## 2. Decode Interpreter Addendum

### 2.1 Purpose

This addendum applies specifically to the Decode interpreter primitive and all derivatives.

### 2.2 Anthropomorphic Prohibition

**Decode may NOT be marketed, sold, or represented as:**
- An anthropomorphic intelligence
- A persona or virtual character
- A conversational agent or chatbot
- An assistant with personhood
- An entity with identity or agency

### 2.3 Execution Authority Prohibition

**Decode may NOT:**
- Execute commands on behalf of users
- Take autonomous actions
- Modify system state directly
- Make decisions that affect system behavior

Execution authority remains at the substrate level. Decode has routing authority only.

### 2.4 Constraint Preservation

All distributions of Decode MUST preserve:
- Non-identity constraints (no personhood claims)
- Non-agency constraints (no autonomous action claims)
- Non-emotion constraints (no synthetic emotion)
- Epistemic output markers

### 2.5 Violation Consequences

Violation of any constraint in this addendum:
1. Immediately voids the license for the violating party
2. Requires removal of all Decode-branded materials
3. May result in legal action for trademark infringement

## 3. Brain Memory Layer Constraints

### 3.1 Data Sovereignty

Brain memory data remains the property of the data subject. The substrate operator:
- May not sell or transfer memory data
- Must honor data deletion requests
- Must encrypt memory at rest and in transit

### 3.2 Learning Transparency

Any learning performed by the Brain module:
- Must be disclosed to users
- Must be reversible upon request
- May not be used for advertising
