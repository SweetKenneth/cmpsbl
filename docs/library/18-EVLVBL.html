What Is EVLVBL?

EVLVBL (pronounced "evolvable") is a standalone code evolution platform that wraps your existing functions with self-healing, shadow testing, and deterministic repair capabilities. It is the commercial product derived from the CMPSBL substrate's internal Immunity Mesh.

Unlike monitoring tools that tell you something broke, EVLVBL fixes it — automatically, safely, and with a full audit trail.

How It Works

1. Wrap

Use wrap() to add self-healing to any async function. No rewrites required — your existing code stays exactly as it is.

import { wrap } from '@evlvbl/sdk';

const resilientFn = wrap(myFunction, {
  repair: 'deterministic',
  shadow: true,
  rollback: 'automatic',
});

2. Shadow

Test changes before they go live. Shadow mode runs your baseline and candidate functions against the same input, comparing outputs and timing without affecting production.

3. Repair

When failures occur, EVLVBL applies repair strategies from a registry of 12+ deterministic approaches — retry, fallback, circuit-break, graceful degradation, and more.

4. Stamp

Every mutation is recorded with a cryptographic evolution stamp — a verifiable proof that the system changed, why it changed, and what the outcome was.

Shadow Probes

Shadow probes are an interactive simulation tool available in the EVLVBL Dashboard. They allow you to:

  1. Define a JSON input payload
  2. Run it against a baseline function and a candidate function
  3. Compare execution timing (baseline vs. candidate latency)
  4. See whether outputs match or diverge
  5. Make informed decisions about deploying changes

Shadow probes never affect production traffic. They run in an isolated context with no side effects.

Learning Tests

Learning tests are designed to help you understand what EVLVBL can automate for your codebase before you commit to a tier.

Getting Started

npm install @evlvbl/sdk

Then wrap your first function:

import { wrap } from '@evlvbl/sdk';

const safe = wrap(myFunction, { repair: 'deterministic' });
const result = await safe(input);

That's it. Your function now self-heals.
