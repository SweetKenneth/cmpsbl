## What is the Capabilities Depot?

The Capabilities Depot is a **free exploration layer** containing 400+ atomic cognitive capabilities across 21 modules. Capabilities are stateless building blocks — use them freely to learn, experiment, and prototype.

**Engines are the products. Capabilities are adoption fuel.**

---

## Key Principles

### 1. FREE to Use
- All 400+ capabilities are unlocked
- Spanning 21 modules across 6 architectural layers
- Explore freely in terminal, CodeLab, or via API

### 2. Atomic & Stateless
- Each capability does one thing well
- No persistence, governance, or versioning
- Combine them however you want

### 3. Adoption Wedge
- Capabilities demonstrate substrate value
- When you need governance, versioning, and production guarantees → upgrade to **Engines**

## How to Use Capabilities

### Via Terminal
```bash
substrate.run capability_name --input "your input"
```

### Via CodeLab
Browse capabilities at `/codelab` and execute with one click.

### Via API
```typescript
import { substrate } from './lib/substrate';

const result = await substrate.capability.run('capability_name', {
  input: 'your input'
});
```
