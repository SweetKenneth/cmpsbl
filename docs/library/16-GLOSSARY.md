| Term | Definition |
|------|-----------|
| **Agency** | A team of AI agents configured to work together on tasks |
| **ARCHITECT Epoch** | Current version era (v9.1.0) — focuses on infrastructure-layer modules |
| **BYOK** | Bring Your Own Keys — users provide their own AI provider API keys |
| **Capability** | A registered, composable unit of functionality within the substrate |
| **Circuit Breaker** | A failure isolation mechanism that stops a module from accepting requests when unhealthy |
| **Cognitive Loop** | The continuous cycle of observe → learn → remember → improve → observe |
| **Confidence Score** | A 0.0–1.0 value indicating how reliably the system knows a piece of information |
| **Crown Jewel** | A capability classified as architecturally sensitive, restricted to internal use only |
| **Decay Curve** | The rate at which memory confidence decreases over time without reinforcement |
| **Dream Cycle** | An autonomous learning session that occurs during idle time |
| **Dream Pool** | Shared learning space where multiple agents contribute and access collective insights |
| **Edge Function** | A serverless function running at the network edge (Deno runtime) |
| **Engine** | A specialized processing system within a module |
| **Evolution Stamp** | A cryptographic receipt proving a self-modification occurred and can be verified |
| **FNDTN** | Foundation — early-stage documentation and architecture |
| **Knowledge Graph** | A structured network of connected memories and concepts |
| **Meta-Engine** | A composite system combining multiple engines |
| **Module** | An isolated functional unit with its own circuit breaker and health score |
| **Module Parity** | The standard ensuring all 21 modules implement required interfaces |
| **RIPPLE** | The typed event bus that serves as the substrate's inter-module communication system |
| **RLS** | Row-Level Security — database-level data isolation per user |
| **SEBA** | Self-Evolving Bounded Agent — an earlier architectural era |
| **Session Reflection** | A periodic review of all module activity to extract meta-insights |
| **Substrate** | The complete CMPSBL cognitive orchestration system |
| **Synergy Pipeline** | A cross-module orchestration workflow combining multiple capabilities |
| **Tier** | Subscription level (Free, Pro, Enterprise, CMPSBL-Only) |
