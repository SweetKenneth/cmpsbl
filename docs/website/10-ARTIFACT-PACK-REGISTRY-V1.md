## Philosophy

Each Artifact Pack solves a clearly defined operational problem. Packs are self-contained in outcome, contain at least one substrate-native capability, and do not duplicate another pack's primary purpose. Internal naming conventions (Crown, Meta, Resolver, etc.) are never exposed publicly.

Packs are activated via Artifact Slots. No feature-based pricing. The substrate runtime remains unified for all users.

## Pack Registry

### MEMORY & CONTEXT (3 packs)

#### 1. Persistent Memory
- **Tier:** Base | **Slots:** 1
- **Purpose:** Tiered recall with contradiction detection, adaptive capacity limits, and spaced repetition
- **Use Cases:** Long-running projects; agents that retain and evolve context over weeks/months
- **Substrate-Native:** Tiered memory architecture (hot/warm/cold/archive) with metacognitive assessment
- **Activation Surface:** Memory module configuration
- **Upgrade Path:** → Dedicated Memory Partitions (enterprise)

#### 2. Dedicated Memory Partitions
- **Tier:** Enterprise | **Slots:** 2
- **Purpose:** Isolated memory domains per project with custom retention policies, compression, and archival
- **Use Cases:** Enterprise teams managing multiple AI projects with strict data separation
- **Substrate-Native:** Per-project memory namespace isolation with adaptive limit scaling
- **Activation Surface:** Project-level memory configuration
- **Upgrade Path:** Terminal (highest memory tier)

#### 3. Context Intelligence
- **Tier:** Professional | **Slots:** 1

- **Use Cases:** Large input volumes where only the most relevant context should surface
