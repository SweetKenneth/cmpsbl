Model-Agnostic Health-Weighted AI Routing

NEXUS Fleet: Intelligent Multi-Provider Orchestration

Kenneth E. Sweet Jr. · ORCID: 0009-0001-4237-1243
PromptFluid® · CMPSBL.com
DOI: 10.5281/zenodo.18234909

Abstract. We present NEXUS Fleet, a model-agnostic AI routing architecture that selects providers based on real-time health scores, latency measurements, cost optimization, and governed daily budget allocation. The router operates across 13 providers with automatic failover cascades, circuit breaker isolation, and a governed daily capacity of 236,000+ requests. Unlike static load balancers, NEXUS Fleet incorporates behavioral health scoring where provider reputation is continuously updated based on observed reliability.
Disclaimer: The designation "novel architecture" reflects the author's assessment based on comprehensive review of publicly available AI routing systems as of February 2026. The author welcomes identification of prior art.

1. The Provider Lock-In Problem

Most AI applications are tightly coupled to a single model provider (OpenAI, Anthropic, Google). This creates single points of failure, vendor lock-in, and no ability to optimize across providers based on real-time performance characteristics.

2. Architecture

NEXUS Fleet implements four routing dimensions:

DimensionMechanism
Health scoringEach provider maintains a rolling health score based on success rate, latency, and error patterns. Unhealthy providers are deprioritized or circuit-broken.
Priority cascadeProviders are ordered by priority. When the primary provider fails or is rate-limited, requests automatically cascade to the next healthy provider.
Budget governanceDaily request budgets are allocated per provider with an 80% safety margin. Budget exhaustion triggers cascade to the next provider.
Cost optimizationFree-tier providers are prioritized. Paid providers are reserved for high-priority or specialized requests.

3. Fleet Composition

The current fleet spans 13 providers including Groq, Cerebras, SambaNova, Together AI, DeepSeek, Google Gemini, Mistral, Cohere, HuggingFace, Cloudflare Workers AI, Novita AI, Chutes AI, and OpenRouter-bridged models. All providers are accessed through a unified interface that normalizes request/response formats.

5. Prior Art Assessment

API gateways (Kong, AWS API Gateway) handle routing but lack health-weighted provider selection. LLM routers (OpenRouter, LiteLLM) provide multi-provider access but lack governed budget allocation, circuit breaker integration, and real-time health scoring that influences routing decisions.

6. Significance

NEXUS Fleet eliminates single-provider dependency while optimizing for cost, reliability, and performance simultaneously. The governed budget system ensures predictable resource consumption, making the routing layer suitable for production deployments with strict cost controls.
