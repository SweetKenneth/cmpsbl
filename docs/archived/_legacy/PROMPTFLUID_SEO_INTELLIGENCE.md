## Core SEO Principles

### Core Web Vitals
- **LCP:** <2.5s (optimize images, CDN, preload critical resources)
- **FID:** <100ms (break up long tasks, defer non-critical JS)
- **CLS:** <0.1 (set image dimensions, reserve space for ads)
- **INP:** <200ms (optimize JS execution, use requestIdleCallback)

### Technical SEO
- Title tags: 50-60 chars, keyword-first
- Meta descriptions: 150-160 chars with CTA
- Single H1 per page with primary keyword
- Semantic HTML: header, main, article, section, aside, footer
- Alt text on ALL images with descriptive keywords
- Schema markup: Product, LocalBusiness, FAQ
- Canonical tags to prevent duplicate content

### Content Strategy: Pillar/Cluster Architecture
