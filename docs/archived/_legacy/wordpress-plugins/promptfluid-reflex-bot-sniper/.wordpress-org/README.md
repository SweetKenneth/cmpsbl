# WordPress.org Assets

This directory contains the banner and icon images required for WordPress.org plugin directory listing.

## Required Assets

- `banner-772x250.png` - Low-resolution banner
- `banner-1544x500.png` - High-resolution banner (retina)
- `icon-128x128.png` - Plugin icon (small)
- `icon-256x256.png` - Plugin icon (large/retina)

## Design Guidelines

- Use PromptFluid brand colors: #7A5FFF, #01C9E8
- Include "PromptFluid Clarity" branding
- Show fluid/flowing design elements
- Keep text minimal and readable
