**Common Questions About CMPSBL®**

## General

### What is CMPSBL?

CMPSBL® (Composable) is a cognitive infrastructure layer for AI applications. It provides memory, learning, multi-provider AI routing, security, and self-evolution capabilities. Think of it as the "operating system" for AI — 21 modules across 6 layers working together.

### How is this different from OpenAI or Anthropic?

We don't compete with AI model providers — we make them more valuable. CMPSBL sits between your application and AI providers, adding memory, learning, security, and intelligent routing. You can use any AI provider (or multiple) through CMPSBL.

### Do I need to use a specific AI provider?

No. CMPSBL is model-agnostic and provider-agnostic. You can use OpenAI, Anthropic, Google AI, Mistral, open-source models, or any combination.

### Can the system really improve itself?

Yes. The MODERNIZER module identifies improvement opportunities and generates proposals. Significant changes go through human approval before being applied. The system compounds its own improvements over time.

## Technical

### What technology stack does CMPSBL use?

- **Frontend:** React + TypeScript + Vite + Tailwind
- **Backend:** PostgreSQL + Edge Functions
- **AI:** Model-agnostic, connects to any provider
- **Infrastructure:** Runs on any cloud or on-premise

### Can I self-host CMPSBL?

Yes. You can license the substrate for your own infrastructure at [LNCHBL.com](https://lnchbl.com). Enterprise tier includes source code access.

### How does memory work?

CMPSBL features a multi-tier memory system that automatically manages the full lifecycle of stored knowledge. Active memories are instantly accessible, while older memories are intelligently compressed and archived — never lost. Core identity and safety memories are immutable and protected.

### What about data privacy?

With a licensed substrate, your data stays entirely on your infrastructure. On the master substrate, strict data isolation ensures your data is never shared or used for training.

## Comparison

### How is this different from LangChain?

LangChain is a library — you still build everything yourself. CMPSBL is a complete cognitive system with 21 integrated modules.

| Aspect | LangChain | CMPSBL |
|--------|-----------|--------|
| Type | Library | Infrastructure |
| Memory | You build it | Built-in, multi-tier |
| Learning | None | Autonomous |
| Security | You build it | Built-in |
| Evolution | None | Self-improving |

### How is this different from Mem0?

Mem0 focuses on memory. CMPSBL includes persistent memory plus 20 other integrated modules for routing, security, learning, observability, orchestration, and more.

### Why haven't others built this?

They have, partially. There are memory solutions, routing solutions, security solutions. No one has integrated them into a coherent cognitive system that compounds its own improvements. Integration is the hard part.
