# SEO — 03 Technical SEO Operations

## Active Technical Features

- Open Graph metadata
- Canonical URLs
- Semantic heading hierarchy
- Image alt discipline
- Lazy loading where applicable
- Noindex for internal/admin routes

## Operational Checks

- Validate route coverage in SEO map
- Validate title and description limits
- Validate OG image availability
- Validate keyword uniqueness

## Usage Principle

Treat SEO as a governed release artifact with repeatable verification checks.
