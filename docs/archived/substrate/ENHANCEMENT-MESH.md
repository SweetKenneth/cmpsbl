# Enhancement Mesh v1.0.0 — "Ambient Intelligence Fabric"

> Always-on substrate amplification layer providing passive technological uplift to all 40 nodes.

---

## Concept

The Enhancement Mesh is a system layer distinct from activation rules. Where activation rules fire on signals (event-driven), Enhancement Mesh amplifiers are **always active**, running on heartbeat intervals. They provide ambient intelligence that elevates every node's baseline performance without requiring triggers.

### Key Principles

1. **Heartbeat, not event-driven** — Amplifiers pulse at fixed intervals (60s–300s), continuously enriching the substrate
2. **Fan-out to all 40 nodes** — Every amplifier's output broadcasts to every node in the matrix
3. **Non-governable** — Cannot be disabled by GOVERNANCE mode changes; structural substrate infrastructure
4. **Uplift scoring** — Each amplifier quantifies its contribution (0–100); aggregate mesh uplift = total technological advantage

## Uplift Scoring

Each amplifier maintains a quantified uplift score (0–100) using EMA-weighted blending:

```
upliftScore = (previous × 0.85) + (raw × 0.15)
raw = baseUplift + priorityBonus + consistencyBonus
```

- **baseUplift**: Category-dependent (cognitive: 85, resilience: 90, operational: 80, governance: 88, evolution: 75, observability: 70)
- **priorityBonus**: `max(0, (10 - priority) × 0.5)` — higher priority = more uplift
- **consistencyBonus**: `min(10, heartbeatCount × 0.01)` — longer uptime = more uplift

Aggregate mesh uplift is a weighted composite matching the health formula.

---

## Degradation Behavior

- Amplifiers track `consecutiveFailures`
- At 3+ consecutive failures: amplifier marked `healthy: false`
- Category health = `(healthy ticks / total ticks) × 100`
- 3+ failures in a category window → `warning` alert
- 5+ failures → `critical` alert
- Mesh never shuts down — degraded amplifiers continue attempting heartbeats

---

## Governance Immunity

Enhancement Mesh amplifiers are **immune to governance mode changes**. Even in EMERGENCY mode, the mesh continues running. This is by design:

- The mesh is structural infrastructure (like blood flow)
- Disabling it would reduce the substrate's baseline capability
- Governance can monitor mesh health but cannot gate its operation
