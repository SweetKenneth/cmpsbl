**Version:** v13.1.0 — IRONCLAD Epoch

## Modules

DECODE, ENCODE, VISION, CORTEX, NEXUS, ECONOMY, SANDBOX, INCLUSIVE, MEDIC, INTEGRATION

## Sector Role

Execution modules translate intent into runnable, governable outcomes. This is the largest sector (10 nodes).

## Key Principles

- NEXUS is routing authority — 14-provider fleet with real-time health tracking.
- CORTEX handles orchestration composition and pipeline management.
- SANDBOX isolates risky execution in contained environments.
- MEDIC provides autonomous diagnostics and self-repair coordination.
- INTEGRATION boots last in execution chain.

## Recent Additions (v12–v13)

- **MEDIC** — promoted to full execution-tier module for autonomous health management
- **NERVE** — moved OUT of execution to OCG (it is the grid's signaling backbone)
