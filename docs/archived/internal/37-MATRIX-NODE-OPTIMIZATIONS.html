1. Architecture

All optimizations live in src/lib/substrate/node-optimizations/, organized by sector:

node-optimizations/
├── index.ts                    ← barrel export
├── core-optimizations.ts       ← CORE sector (2 optimizations)
├── ccr-optimizations.ts        ← CCR sector (8 optimizations)
├── ccl-optimizations.ts        ← CCL sector (10 optimizations)
├── execution-optimizations.ts  ← Execution sector (18 optimizations)
└── overlay-optimizations.ts    ← Overlay sector (10 optimizations)

Each optimization is a self-contained, stateless-safe module with its own interfaces, in-memory stores (bounded), and public API. No optimization mutates any existing substrate structure.
