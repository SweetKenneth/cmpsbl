1. Architecture Overview

The Minds Intelligence Layer is a modular capability stack that powers all Mind agents. It provides domain-specific intelligence, tool orchestration, memory management, and quality assurance — all governed by a centralized feature flag matrix that separates public features from internal-only capabilities.

3. Public vs Internal Capability Separation

Public (Phase 1)

  • Scoped Research: Each Mind has curated domain whitelists (e.g., Sales Mind can only research LinkedIn, Crunchbase, Bloomberg). Enforced at tool execution.
  • Tool Chains: Pre-defined multi-step workflows (research→summarize→draft→format). Configurable per Mind.
  • Prompt Scaffolding: Every Mind has a hardened system prompt with domain-specific reasoning (MEDDIC for Sales, Bloom's for Educator, IRAC for Legal).
  • Failure Recovery: 10 failure categories with deterministic playbooks. No generic apologies. Structured retry→fallback→degrade paths.
  • Context Windowing: Signal-weighted memory (recency 35% + relevance 45% + frequency 20%). Token budget enforcement. Pinnable entries.
  • Confidence Signaling: Every output includes confidence score and level. Rubric is hidden — users see explanations, not weights.

Internal Only

  • Memory Consolidation: Background trigram-based deduplication, value strengthening, and content compression. No UI.
  • Quality Scoring: 6-dimension rubric (completeness, structure, specificity, actionability, tone, safety). Scores outputs before return.
  • Adaptive Tone: Learns from message length, emoji use, jargon, and formality signals. Auto-shifting OFF; manual selector available.
  • Vocabulary Registry: Seed glossaries per Mind (MEDDIC, DRY, IRAC, Bloom's, STRIDE, etc.). CLM-driven growth internal only.
  • Proficiency Gating: 5-tier system (Novice→Master). Capability unlocking infrastructure built but enforcement disabled.

4. Versioning and Snapshot Model

Minds use a snapshot-based versioning system that separates public releases from internal learning:

  • Public Release: Immutable, version-tagged (v1.0) snapshot. Freezes prompts, scopes, chains, vocabulary, and tone.
  • Internal Head: Continues learning via CLM. Version tracked as v1.0.X-dev.
  • Promotion: Internal head promoted to new public release (v1.1) with changelog. Triggers auto-snapshot.
  • Integrity: Snapshots include scaffold hash and scope fingerprint for drift detection.

5. Security & Scope Enforcement

  • Research Scope: URL validation enforced before any external request. Blocked domains include localhost, private IP ranges.
  • Confidence Rubric: Internal weights (sourceQuality: 25%, dataCompleteness: 20%, etc.) never exposed. Users see levels + generic factors.
  • Quality Scoring: Safety dimension checks for leaked internals (rubric mentions, system prompts, API keys). Auto-penalizes.
  • Tool Chain Timeouts: Every step has mandatory timeout (5-30s). Exponential backoff with 30s cap.
  • Context Window: Token budget enforcement prevents memory overflow. Stale windows auto-cleanup after 1 hour.
  • Feature Flags: Cross-Mind Transfer and Contradiction Resolution explicitly excluded — activatableViaFlag: false.
