5. Database Security — RLS Fix

CRITICAL The defense_events table had a blocking RLS violation that prevented the client-side Site-Guard module from recording bot detection telemetry.

Fix: Added INSERT policies for both anon and authenticated roles, enabling threat telemetry from any authentication context.

CREATE POLICY "Anon can insert defense_events"
  ON public.defense_events FOR INSERT TO anon WITH CHECK (true);

CREATE POLICY "Authenticated can insert defense_events"
  ON public.defense_events FOR INSERT TO authenticated WITH CHECK (true);
