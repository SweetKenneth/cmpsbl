What Is EVLVBL?

EVLVBL (pronounced "evolvable") is an API-first code evolution platform. Unlike downloadable SDKs, the entire self-evolution engine runs on CMPSBL's servers — developers interact via simple HTTP API calls from any language or framework.

Unlike monitoring tools that tell you something broke, EVLVBL fixes it — automatically, safely, and with a full audit trail. And unlike open-source SDKs, the proprietary algorithms never leave our infrastructure.

How It Works

1. Get Your API Key

Sign up at cmpsbl.com/evolution-mesh to get your free API key. Free tier includes 1,000 calls/month.

2. Call the API

Send your inputs and schema via a simple HTTP POST. The engine validates, repairs, and returns clean results.

POST https://api.cmpsbl.com/v1/wrap
Authorization: Bearer YOUR_API_KEY

{
  "input": { "email": "test@test.com", "age": -5 },
  "schema": { "email": "string", "age": "number" },
  "repair": "deterministic"
}

→ { "result": { "email": "test@test.com", "age": 0 }, "repaired": true }

3. Shadow Test

Test changes before they go live. Shadow mode runs your baseline and candidate functions against the same input, comparing outputs and timing without affecting production.

POST https://api.cmpsbl.com/v1/shadow

{
  "baseline_result": { ... },
  "candidate_result": { ... },
  "input": { ... }
}

4. Evolve

Every mutation is recorded with a cryptographic evolution stamp — a verifiable proof that the system changed, why it changed, and what the outcome was.

The VOLVER Coding Agent

EVLVBL includes VOLVER, a built-in coding agent available via the /v1/volver API endpoint. VOLVER operates in analysis mode — it tells you what it would do, without doing it.

VOLVER is available on Enterprise plans. Free and Pro tiers can test VOLVER's capabilities via Learning Tests on the dashboard.

Getting Started

No packages to install. Just get your API key and make an HTTP call:

curl -X POST https://api.cmpsbl.com/v1/wrap \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input": {"email": "test@test.com"}, "schema": {"email": "string"}, "repair": "deterministic"}'

That's it. Your input is now self-healing.
