1. What Are Meshes?

Meshes are cross-cutting behavioral overlays that operate across all modules. Unlike modules (which have a specific functional domain), meshes enforce system-wide properties like security, resilience, self-improvement, intent resolution, and ethical constraints.

Meshes boot after modules and operate as ambient services — they observe, intercept, and augment module behavior without modules needing to know about them.

PropertyValue
PurposeSecurity perimeter

  • Rate Limiting — Adaptive per-endpoint and per-user limits

3. IMMUNITY Mesh

PropertyValue
PurposeAdaptive resilience and self-healing
Sourcesrc/lib/substrate/modernizer-shadow-resolver/
DependenciesCORE, DEFENSE

Capabilities

  • Executor Shadow Training — Executors practice fixing real system gaps in shadow mode
  • Gap Classification — Categorizes system gaps into 6 types: security, resilience, performance, config, cleanup, observability
  • Self-Healing Patterns — Automatically detects and recovers from known failure patterns
  • ENCODE Escalation — Failed shadow attempts escalate to ENCODE for resolution
  • Learning Rules — ENCODE fixes are converted into reusable learning rules

Metrics

  • Success rate across executors
  • ENCODE assist count
  • Improving/declining executor tracking
  • Gap type distribution
  • Skill growth curves per executor-gap pair

MODERNIZER Absorption

The former MODERNIZER module's responsibilities — upgrade plans, file-level diffs, shadow-to-production deployment, Omega Observer pattern — are now part of EVOLUTION. The modernizer.* facade continues to route to EVOLUTION internals. The useModernizer hook remains functional.

7. Mesh Boot Order

Phase 5 (after Modules): DEFENSE ← Security perimeter first GOVERNANCE ← Ethical constraints second INTENT ← Intent routing third EVOLUTION ← Self-improvement fourth IMMUNITY ← Resilience last (depends on DEFENSE)

DEFENSE boots first because IMMUNITY depends on it. GOVERNANCE boots early to ensure ethical constraints are in place before EVOLUTION starts proposing mutations.
