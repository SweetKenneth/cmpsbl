# V13 — 02 Library Standard

## Standard Rules

1. One subject = one library
2. Each library starts with `00-INDEX`
3. Internal/repo libraries use `.md`
4. Printable stakeholder libraries use `.html`
5. Module names remain in all caps

## Suggested Library Classes

- Internal
- Modules
- Internal Secrets
- Reconstruction
- Operations
- Investor
- Functions
- SEO

## Build-On Notes

When adding a new subject, create a new folder library instead of extending unrelated pages.
