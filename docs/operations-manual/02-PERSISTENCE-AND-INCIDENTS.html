02 — Persistence & Incident Response

Persistence Discipline

  1. Use leader lease control for periodic snapshots.
  2. Commit staged state atomically.
  3. Append and retain WAL for replay/recovery.
  4. Keep manual flush path available.

Incident Runbook

  1. Classify incident (module, cascade, persistence, governance).
  2. Contain impact quickly.
  3. Recover stable baseline.
  4. Validate integrity and audit evidence.

Recovery Principle

Prioritize continuity first, then full restoration and post-incident hardening.
