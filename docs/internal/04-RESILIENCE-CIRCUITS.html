Why the System "Never Crashes"

Circuit Breaker Pattern

Each module has its own independent circuit breaker that prevents cascading failures:

┌───────────────────────────────────────────────────────────┐ │ CIRCUIT BREAKER STATES │ ├───────────────────────────────────────────────────────────┤ │ │ │ ┌────────┐ 3 failures ┌────────┐ │ │ │ CLOSED │──────────────────►│ OPEN │ │ │ │(normal)│ │(blocked)│ │ │ └────────┘ └────────┘ │ │ ▲ │ │ │ │ 2 successes 60s timeout │ │ │ │ │ │ │ ┌────────────┐ │ │ │ └───────│ HALF-OPEN │◄──────┘ │ │ │ (testing) │ │ │ └────────────┘ │ └───────────────────────────────────────────────────────────┘
🔐 The Isolation Secret: Each module has its own independent circuit breaker. If BRAIN fails 3 times, only BRAIN is blocked—other modules continue. This isolation prevents partial failures from cascading into full outages.

Auto-Heal Trigger

When any module's health drops below 40%:

  1. System triggers system.heal automatically
  2. Module is put into "recovery mode"
  3. Heal attempts are logged and rate-limited
  4. If 3 heals fail, escalate to admin alert

Health Score Calculation

health = 100 - (consecutive_failures × 20)
status = health >= 70 ? 'healthy' : health >= 40 ? 'degraded' : 'critical'
