1. What the Foundry Does

  • Discovers latent capabilities by combinatorially exploring the 38-node topology
  • Scores each via CJPI (Crown Jewel Pipeline Index)
  • Tiers into Apex / Mythic / Relic / Prime / Mint quality bands
  • Deduplicates semantically (cosine > 0.92)
  • Fingerprints structurally (SHA-256, epoch-scoped, immutable)
  • Persists to the S-Tier Vault (governor-only)

2. Reactor Core Loop

while (budget_remaining && candidates_exist) {
  candidate = generate_candidate(topology, module_combinations)
  fingerprint = SHA-256(canonical({steps, epoch}))
  score = cjpi_score(candidate)
  tier = auto_tier(score)
  if (!is_duplicate(candidate, existing)) persist(candidate, score, tier, fingerprint)
}
