ENGINEER Node
Mechanist

The substrate's internal maintenance node. No user-facing UI — operates entirely behind the scenes, polling system health, generating findings and proposals, and dispatching to INTEL.

CMPSBL® Memory Stream · IRONCLAD Epoch · Control Plane First-Class Citizen

1. Position in Control Plane

ENGINEER → INTEL → ATLAS (Node Inbox)

ENGINEER is a Control Plane first-class citizen alongside INTEL, DECODE, AUDIT, and the NEXUS-CLM Bridge.

4. Proposal Generation

When a finding warrants action, ENGINEER generates proposals dispatched to ATLAS for governor approval:

pending → approved / rejected → executed

5. INTEL Dispatch

Every finding is immediately dispatched to INTEL via intelAggregator.ingest(). Fingerprinting enables deduplication — repeated findings for the same issue are coalesced.

6. Safety Constraints

Safety
  • ENGINEER never directly modifies production behavior
  • All proposals require human approval through ATLAS
  • Findings are read-only observations
  • The auto_training_enabled flag gates automated proposal execution
