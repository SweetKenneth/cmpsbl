3. Edge Function Security

HMAC Verification

signature = HMAC-SHA256(secret, timestamp + "." + body)

All inter-service communication uses HMAC-SHA256 signature verification. Internal substrate orchestration functions use SERVICE_ROLE_KEY by design and are excluded from public auth validation.

IP Reputation at Edge

Edge rate limiting and IP reputation checks execute before any application logic. Fallback origin mechanisms ensure valid redirect URLs for checkout functions.

8. Proposal Gate (IMMUNITY Module)

Anomaly detection and learning engines cannot directly mutate live configurations. They must generate proposals validated through a 5-guard pipeline:

GuardFunction
1. Immunity Learning Sandbox100-entry capacity, 1-hour TTL for rule iteration
2. Shadow Mode ValidationTest against production baselines
3. Threshold ClampingAbsolute MIN/MAX bounds + daily delta caps
4. Traffic Spike FreezeBlocks changes during traffic anomalies
5. Auto-RollbackTriggers if FP rate degrades > 5% (rolling buffer of 20 stable snapshots)

10. Black-Box Enforcement

High-value artifacts are protected by the 10-point enforcement interface:

  • No source code visibility for sealed items
  • No prompt/memory leakage
  • No cross-project data bleed
  • Environment signature lock prevents unauthorized deployment
  • Blurred previews and distribution filters exclude proprietary orchestration logic
  • UI-level blocks prevent access to system graphs
