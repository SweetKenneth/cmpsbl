INTEL
Aggregation Pipeline

The substrate's intelligence aggregation and explanation layer. Collects signals from the entire system, normalizes, deduplicates, and converts them into IntelCards for the INTEL Panel.

CMPSBL® Memory Stream · IRONCLAD Epoch · 500-Signal Rolling Window

1. Signal Flow

ENGINEER → INTEL ← VISION
ECONOMY → INTEL ← DEFENSE
SEBA → INTEL → ATLAS

INTEL is a passive aggregator — it receives signals but does not initiate actions.

2. IntelSignal Model

FieldTypeDescription
idstringAuto-generated unique ID
sourcestringEmitting node (e.g., ENGINEER/NEXUS)
categoryIntelCategoryhealth, security, performance, cost, governance, evolution
severitystringinfo, warning, error, critical
headlinestringOne-line summary
detailstringFull explanation
fingerprintstringDeduplication key

3. Deduplication

fingerprint = `${signal.source}:${signal.category}:${signal.headline}`

Duplicates increment count and update last_seen without storing the signal again.

4. Supporting Components

NEXUS-CLM Bridge

Routes CLM cycles through NEXUS for AI-assisted analysis. Results fed back as enriched signals.

Proposal Generator

Auto-creates proposals when severity ≥ error and recurrence ≥ 3. Dispatched to ATLAS Node Inbox.
