1. Circuit Breaker System

CLOSED→ failures ≥ 5 → OPEN→ 30s → HALF-OPEN→ 3 successes → CLOSED
🔒 Production Constants — src/lib/substrate/circuit-breaker/index.ts
DEFAULT_CONFIG = {
  failureThreshold:       5,        // failures before opening
  recoveryTimeout:        30,000,   // ms before half-open
  halfOpenMaxAttempts:    3,        // successes needed to close
  windowSize:            60,000,   // sliding failure window (ms)
  autoRecoveryEnabled:   true,     // automatic recovery timer
  autoRecoveryIntervalMs: 60,000,  // check every 60s
}

State is DB-persisted (circuit_breaker_state). Failure counting uses sliding-window queries against circuit_breaker_failures. Each module has its own independent breaker instance with a totalTrips counter tracking cumulative circuit openings.

2. Cascade Containment (3-Tier)

SeverityTriggerResponse
S1≥ 3 modules fail within 30sOpen breakers on affected downstream
S2Fan-out or cyclic cascadeIsolate origin, quarantine zone
S3Persistent S2 for > 2 minutesActivate Safe Mode (pessimistic integrity: min(A,C,P))

Safe Mode state is durable in substrate_safe_mode. Recovery requires all three lanes above threshold before mode is cleared.

3. Dead Letter Queue

CommandAction
ripple.dlqList all DLQ items
ripple.dlq.retry { id }Re-attempt delivery
ripple.dlq.discard { id }Remove from DLQ
ripple.dlq.purgeRemove all expired

Failed event handlers retry 3× with exponential backoff (100ms, 500ms, 2s). After 3 failures → move to DLQ. Never silently drop events.

4. Retry Budgets (Token Bucket)

10 tokens per 60-second period per module. When tokens = 0, retries blocked until refill.

Exponential Backoff with Jitter

delay = min(baseDelay × 2^attempt + random(0, jitter), maxDelay)

baseDelay: 1,000ms
maxDelay:  30,000ms
jitter:    0–500ms
maxAttempts: 3

8. Self-Healing Recovery (MEDIC Module)

1. Detect degraded health (score < 40 = auto-heal trigger)
2. Identify recovery strategy (circuit reset, state flush, restart)
3. Execute recovery
4. Wait for health re-check
5. If improved: log to audit chain, resume
6. If not: escalate to governor for manual intervention
