1. Reactor Core Loop

1. Generate candidate pool (depth 2–5)
2. For each candidate:
   a. Compute semantic signature (embedding hash)
   b. Compute structural fingerprint (SHA-256, epoch-scoped)
   c. Check dedup index (cosine > 0.92 = skip)
   d. Score via CJPI (4-factor weighted composite)
   e. Auto-tier based on thresholds
   f. Persist with immutable fingerprint
3. Rank within each tier
4. Emit discovery event to RIPPLE

4. Structural Fingerprinting

Identity Rule: Fingerprint = SHA-256(canonical({steps, epoch})). Steps are ordered, capability-aware. CJPI, name, category excluded. Once set, never overwritten. Epoch defaults to SPARTA. WebCrypto SHA-256 only — no fallback hashing.
