2. Quality Engines

Confidence Engine

FactorWeightDescription
Factual accuracy0.30Cross-reference against knowledge base
Writing quality0.25Grammar, structure, readability
Topic relevance0.20Alignment with seed topic and brand voice
Novelty0.15Original perspective vs. existing content
SEO alignment0.10Keyword density, meta quality, structure

Contradiction Engine

Scans for internal contradictions and cross-references existing published posts. Produces a contradiction score (0–100, lower is better) with pass/warn/fail outcome.

Split Brain Evaluation

Reader Perspective

Evaluates from consumer perspective. Score field: split_brain_reader_score

Skeptic Perspective

Challenges claims, finds weaknesses. Score field: split_brain_skeptic_score

if reader ≥ 70 AND skeptic ≥ 60 → publish
if reader ≥ 60 AND skeptic ≥ 50 → review (human)
else → reject

Semantic Drift Detection

Monitors content evolution away from core brand messaging. Tracks drift score, drift direction, and epistemic status of each post's knowledge claims.

3. Publish Governance

draft → review → published / rejected

Global rate limits, category-specific quotas, quality floor enforcement, and manual review queue for borderline content.

4. Monthly Memory Compression

Every 30 days: aggregate lessons learned, distill patterns, update confidence weights autonomously, archive scoring data older than 90 days.
