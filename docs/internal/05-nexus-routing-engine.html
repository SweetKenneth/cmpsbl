3. Routing Modes

Standard Route

Default mode. Selects optimal provider by task classification, health, cost, context window, and affinity.

Stream Route (SSE)

Native SSE support for streaming responses. Maintains open connection, streams tokens as generated.

Consensus Route (2-of-3)

Sends request to multiple providers, requires agreement (e.g., 2-of-3). For critical governance decisions.

Image Route v2 (Pro Cascade)

Google AI Studio (Imagen) → FAL.ai → Stability AI. Automatic fallback on failure with improved retry logic.

5. Resilience Features

Request Coalescing

Auth-aware deduplication of identical in-flight requests. Same hash = same promise returned to all callers.

Exponential Backoff with Jitter

delay = min(baseDelay × 2^attempt + random(0, jitter), maxDelay)
ParameterValue
Base delay1,000ms
Max delay30,000ms
Jitter range0–500ms
Max attempts3

Half-Open Circuit Probes

When a provider's breaker opens → after recoveryTimeout (30s) → half-open → 3 probe successes needed to close → failure reopens with trip counter increment.
