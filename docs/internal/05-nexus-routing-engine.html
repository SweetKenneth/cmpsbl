2. Routing Modes

Standard Route

Default mode. Selects optimal provider by task classification, health, cost, context window, and affinity.

Stream Route

Native SSE support for streaming responses. Maintains open connection, streams tokens as generated.

Consensus Route

Sends request to multiple providers, requires agreement (e.g., 2-of-3). For critical governance decisions.

Image Route v2

Pro-tier cascade: Google AI Studio → FAL.ai → Stability AI. Automatic fallback on failure.

4. Resilience Features

Request Coalescing

Auth-aware deduplication of identical in-flight requests. Same hash = same promise returned to all callers.

Exponential Backoff with Jitter

delay = min(baseDelay × 2^attempt + random(0, jitter), maxDelay)
ParameterValue
Base delay1,000ms
Max delay30,000ms
Jitter range0–500ms
Max attempts3

6. Cost Tracking

Every NEXUS call logs: provider, model, input/output tokens, estimated cost (millicents), response time, success/failure. Daily quota tracking per provider prevents runaway costs.

7. Provider Health Monitoring

  • Uptime — rolling 24h
  • Average response time — P95
  • Error rate — rolling 1h
  • Rate limit hits — rolling 1h

Health scores feed directly into routing weight calculations.
