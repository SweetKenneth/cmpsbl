Node #40

ATLAS

System Map & Capability Registry

Plane Cartographer Gen 2

Executive Summary

ATLAS is the substrate's system map and capability registry. It owns node discovery, capability enumeration, topology visualization, and system-wide metadata. The final node (#40) providing the global view of "what exists and what can it do."

Capabilities

discover

Enumerate all nodes and their capabilities

register

Add new capabilities to the registry

query

Find nodes by capability or sector

visualize

Generate topology maps and diagrams

Discovery Protocol

discover():
  1. Query all 12 sectors in parallel
  2. For each sector, enumerate nodes
     - Send pulse, collect capability manifest
  3. Build unified registry
     - Index by sector, capability, health
  4. Return: Complete system map

Trade Secrets

1. Lazy Discovery with Cache

60-second TTL cache with sector-hinted queries. Only re-discovers nodes likely to have requested capability.

2. Capability Inheritance

Resolution order:
  1. Node direct capabilities
  2. Sector-level capabilities
  3. Global capabilities (CORE)

3. Topology Diffing

Tracks added, removed, and changed nodes/capabilities over time for audit and monitoring.

4. The 80-Capability Map

Authoritative list of 80 capabilities across all 40 nodes, used by CORTEX for orchestration routing.
