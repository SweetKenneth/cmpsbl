◆ Scoped Access Control

API keys carry scope arrays (e.g., ['brain.query', 'decode.chat']). Scope checking happens at the gateway level before any module code executes. A key with brain.query cannot invoke evolution.apply.

◆ Cost Attribution

Every call: (base_cost × complexity) + (tokens × per_token_rate) in millicents. Feeds ECONOMY for chargeback and ROI analysis.

◆ Zero-Plaintext Keys

API keys are never stored in plaintext. Only the prefix (for identification) and SHA-256 hash (for verification) are persisted. Raw key is shown once at generation time.
