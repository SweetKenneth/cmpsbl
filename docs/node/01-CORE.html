Architecture

Boot Sequence

CORE boots in a strict order enforced by initializeSubstrate():

CORE.boot→ CCR.boot→ OCG→ Execution(11)→ ESZ/EPZ/EMZ/CSZ→ Mesh(4)

Triple-Deferred Initialization

CORE uses a triple-deferral strategy to achieve zero main-thread blocking:

document.readyState === 'complete'
  → requestIdleCallback (timeout: 10s)
    → setTimeout(100ms)
      → initializeSubstrate()

This ensures the UI is fully interactive before any substrate work begins. On browsers without requestIdleCallback, a 5-second setTimeout fallback is used.

Yield-to-Main Protocol

Between each boot phase, CORE yields to the main thread using the Scheduler API with a setTimeout(0) fallback. This prevents long-task jank on low-end devices.

Trade Secrets

◆ Trade Secret #1 — 40-Node Pulse Fallback

If either CORE or CCR fails to boot, CORE falls back to pinging every node individually. This is the only place in the substrate where all 40 nodes are iterated sequentially — and it only runs on degraded boot. The health percentage reported (N/40 nodes active) is the ground truth used by ATLAS governance.

◆ Trade Secret #2 — Priority-95 Capability Lock

CORE registers scheduling, health, and boot_sequencing at priority 95 in the Capability Router. No other node can register these capabilities at priority ≥ 95, making CORE the permanent authority for these functions.

◆ Trade Secret #3 — Priority-1 Shutdown

CORE's shutdown system uses a priority queue. The Control Plane persistence hook runs at priority 1 (highest), ensuring all in-flight state is flushed before any other shutdown work. This guarantees zero data loss on tab close or navigation.

Algorithms

Health Calculation

CORE health is binary: either the kernel booted (health: 100) or it didn't (health: 0). There is no degraded state for CORE itself — degradation is tracked at the CCR and individual node level.

Auto-Recovery Engine

After boot, CORE starts the automatic circuit recovery engine (core-circuit-recovery) which monitors all circuit breakers across the matrix and attempts recovery when breakers are in open state.

Subsystem Health Registry

CORE initializes the subsystem health registry which feeds GOAL (Global Observability Access Layer) with per-subsystem health scores across all 12 sectors.
