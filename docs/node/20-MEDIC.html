Trade Secrets

◆ Conservative Circuit Breaker

MEDIC trips at 3 failures, not 5. As the health system, it must be the most reliable node — fails fast to prevent accumulating unreliable diagnostics.

◆ Mutual Health Exclusion

MEDIC never diagnoses itself. Self-diagnosis creates recursive dependency. CORE monitors MEDIC externally via heartbeat.

◆ Ring Buffer State

All state arrays (300/50/300) use ring buffers. Bounded memory growth regardless of system lifetime.
