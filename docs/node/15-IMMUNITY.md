## Architecture

### Threat Lifecycle

```
Threat Detected
  → T-Cell Sentinels (distributed detection, Mahalanobis distance)
  → Cytokine Storm Preventer (proportionality check, ≤1.5× threat)
  → Immune Response Orchestration (quarantine, neutralize)
  → Adaptive Antibody Generator (synthesize rule, ≥0.85 confidence)
  → Immune Memory Bank (persist to taxonomy tree)
  → Pathogen Evolution Tracker (update mutation tree)
  → Convalescence Manager (restore affected nodes)
  → Vaccination Campaign Engine (proactive fleet hardening)
  → Immune Telemetry Nexus (record everything)
```

### Key Algorithms

- **Mahalanobis Distance** — Multivariate anomaly detection (sentinels)
- **Antibody Generalization** — Broadens narrow signatures to family-level patterns
- **Proportionality Engine** — Response severity capped at 1.5× threat level
- **Arms Race Scoring** — Defense vs. attack evolution velocity ratio
- **ISI Composite** — Coverage (35%) + Latency (20%) + FP Rate (25%) + Vaccination (20%)

### Safety Systems

- **Cytokine Storm Prevention** — Max 5 concurrent responses, blast radius scoring, auto-dampening
- **Autoimmune Detection** — Detects immune rules incorrectly targeting healthy behavior
- **Convalescence** — Structured recovery with state integrity verification
- **Antibody TTL** — Rules auto-expire after 180 days if never triggered
