Trade Secrets

◆ Trade Secret #1 — Memory Ownership Principle

All persistent storage MUST flow through MEMORY. Separate standalone persistence subsystems are strictly prohibited. This ensures centralized memory management and cognitive consistency across the 40-node matrix.

◆ Trade Secret #2 — SM-2 Spaced Repetition

MEMORY uses the SuperMemo SM-2 algorithm: easiness = max(1.3, E + 0.1 - (5-q)×(0.08+(5-q)×0.02)). High-quality recalls increase intervals exponentially. Poor recalls reset to 1 day. This ensures frequently-needed knowledge stays accessible while rarely-used knowledge gracefully decays.

◆ Trade Secret #3 — Contradiction Detection Pipeline

New memories are vector-searched against existing entries (threshold 0.8). If sentiment divergence exceeds 0.6, a CONTRADICTION_DETECTED signal routes to CONSCIENCE for ethical resolution. This prevents the substrate from holding conflicting beliefs.

◆ Trade Secret #4 — RAG Audit Provenance

Every RAG retrieval is logged: query hash, result IDs, relevance scores, source attribution. This creates a full provenance trail for any AI-generated content, enabling regulatory compliance and explainability.

Workload-Aware Tiering

  • HOT > 1000 entries → aggressive eviction to WARM
  • WARM latency > 50ms → pre-load popular to HOT
  • COLD accessed >5× in 24h → promote to WARM

Hardening (Vault v2.0.0)

  • Encryption at rest — XOR obfuscation for WARM tier
  • Access audit trail — Every read/write logged with caller identity
  • Quota enforcement — Per-tier entry limits
  • Integrity checksums — SHA-256 on COLD/LEGACY entries
