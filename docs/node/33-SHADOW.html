SHADOW

Isolated Testing & Divergence Analysis

CSZ Doppelgänger Gen 1

Executive Summary

SHADOW is the substrate's isolated testing ground. It runs proposed mutations against production traffic in complete isolation, measures divergence, and reports results to the SEBA promotion pipeline. SHADOW is Gate 3 — mandatory and non-bypassable.

Shadow Run Lifecycle

INIT

Provision environment, apply mutation

MIRROR

Traffic flows to shadow alongside prod

EXECUTE

Both process identical inputs

COMPARE

Outputs compared for divergence

SCORE

Divergence metrics computed

TEARDOWN

Shadow environment destroyed

Divergence Scoring

divergence_score = 0.50 × output_div 
                 + 0.30 × latency_div 
                 + 0.20 × error_div

Promotion thresholds:
  - Output divergence:  < 5%
  - Latency divergence: < 10% degradation
  - Error divergence:   < 1% increase
  - Total score:        < 0.05 for promotion

Trade Secrets

1. Zero Production Write Access

Shadow execution has zero write access to production state. All side effects are captured in an ephemeral store destroyed on teardown.

2. Time-Bounded Execution

Shadow environments have a configurable TTL (default: 1 hour). Automatic teardown prevents resource leaks.

3. Network Interception

All outbound network calls from shadow can be intercepted, recorded, or blocked — preventing external system contamination.

4. TSAC (Truth Shadow Arbitration Check)

  • Truth assertion: Verify shadow outputs are factually consistent
  • Shadow verdict: Pass/warn/fail based on thresholds
  • Arbitration: Resolve conflicts between multiple shadow runs
