Executive Summary

INTENT resolves high-level goals into actionable plans. It owns intent classification, goal decomposition, action sequencing, and execution orchestration. INTENT bridges "what the user wants" and "what the system does."

Goal Decomposition Algorithm

decompose(goal):
  1. Identify goal type
     - Simple: Single action
     - Compound: Multiple independent actions
     - Sequential: Dependent action chain
     - Conditional: Branching on intermediate results
  
  2. Extract sub-goals
     - Identify logical boundaries
     - Determine dependencies
     - Assign to appropriate nodes
  
  3. Build dependency graph (DAG)
  
  4. Return: ActionPlan with structure

Trade Secrets

1. Ambiguity Surfacing

Rather than guessing, INTENT explicitly surfaces ambiguities. If confidence < 0.7, it requests clarification before proceeding.

2. Parallel Execution Detection

detectParallelism(actionPlan):
  1. Topological sort of action DAG
  2. Identify actions with no mutual dependencies
  3. Group into parallel execution sets

3. Rollback Planning

Every action plan includes a rollback strategy:

  • Compensating: Run reverse actions
  • Checkpoint: Restore from snapshot
  • None: Idempotent, no rollback needed
