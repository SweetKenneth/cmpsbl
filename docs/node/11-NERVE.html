Signal Emission Pipeline

Every signal passes through a 4-gate pipeline before delivery: Dedup → Circuit → Backpressure → Deliver. This order is critical — dedup is O(1) and cheapest, circuit prevents wasted work on broken paths, backpressure evaluates pressure levels last.

Emission Algorithm
emitSignal(from, to, type, payload, options):
  1. DEDUP — Check idempotency key (2,000-entry cache, 5s window)
  2. CIRCUIT — Reject if destination circuit OPEN + in cooldown
  3. BACKPRESSURE — If CRITICAL, only pass priority=critical
  4. DELIVER — matrixBroadcast (to='*') or nodeSignal (targeted)
  5. RECORD — Track latency, increment stats, reset circuit on success

Deduplication Engine

2,000-key LRU cache with 5-second window. Two-phase eviction: window-based expiry first, then hard-cap oldest deletion.

Trade Secrets

◆ First-Detection-Only Broadcast

Dead node announcements use missedCount === 1 — exactly one broadcast per death event. Prevents announcement storms during sustained outages.

◆ Priority Signal Bypass

priority: 'critical' signals bypass backpressure gates entirely. System-critical signals always reach their destination regardless of downstream load.

◆ Self-Heartbeat

NERVE calls registryHeartbeat('nerve') at the end of every cycle to prevent itself from being falsely marked as dead.
