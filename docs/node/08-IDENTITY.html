◆ Anti-Escalation Architecture

Roles live in a separate table with SECURITY DEFINER functions. No RLS recursion, no client-side role manipulation, no privilege escalation via profile updates. This is the most critical security invariant in the substrate.

◆ Session Fingerprinting
fingerprint = SHA-256(userAgent + language + timezone + screenRes + colorDepth)

Hashed characteristics only — no PII storage. Used for returning-user detection across sessions.

◆ Governor Gate

Governor access: has_role(auth.uid(), 'governor') via server-side RPC. Never client-side checks, never localStorage, never hardcoded credentials. Every verification logged to AUDIT.
