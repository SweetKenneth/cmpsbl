Bottleneck Detection

detectBottleneck(profiles[]):
  1. Identify slowest node (>50% of total latency)
  
  2. Check resource saturation:
     - CPU > 80% → compute-bound
     - Memory > 85% → memory-bound
     - I/O > 70% → I/O-bound
  
  3. Check queue depths for backpressure

Trade Secrets

1. Auto-Tuning Parameters

Tunable: connection pools, worker threads, batch sizes, cache sizes, timeouts, queue depths. Incremental adjustments (±10%) with automatic reversion on degradation.

2. Resource Allocation Strategy

If demand > available:
  - Priority-weighted allocation
  - Minimum guarantee: 10% of request
  - Notify CORTEX of constraints

3. Predictive Scaling

Uses 7-day historical profiles with seasonal model (hour + day patterns) plus 20% headroom for variance.

4. Performance Regression Detection

  • Latency P95 increase > 20%
  • Throughput decrease > 15%
  • Error rate increase > 5%
