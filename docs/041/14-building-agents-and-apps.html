Application Patterns

  • Chat Application — Memory recall → context → reasoning → response → storage
  • Agent — Task → context → tool chain → execution → recovery → result
  • Copilot — Activity → suggestion → confidence → user decision → outcome
  • Workflow — Trigger → intent → CORTEX orchestration → parallel execution

Chatbot Example

async function chat(userMessage, sessionId) {
  const context = await fetch(API, { method: 'POST', headers: {...},
    body: JSON.stringify({ module: 'memory', action: 'semantic_search',
      input: { query: userMessage, limit: 5 } })
  }).then(r => r.json());

  const response = await fetch(API, { method: 'POST', headers: {...},
    body: JSON.stringify({ module: 'brain', action: 'query',
      input: { prompt: userMessage, context: context.data } })
  }).then(r => r.json());

  return response.data.reply;
}
