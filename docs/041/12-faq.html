12 — FAQ

General

What is CMPSBL?

A cognitive substrate — a runtime operating system providing persistent memory, autonomous discovery, governed evolution, and portable capability exports.

Is CMPSBL a framework, library, or platform?

A platform. An operating system for cognitive applications.

What makes it different?

Autonomous discovery (Memory Stream), crystallization (discoveries → exportable artifacts), and governed evolution (mandatory consent).

Architecture

What is a node?

An autonomous subsystem. 40 primitives, 4 categories.

How do nodes communicate?

Through the INTENT routing protocol. Never directly.

Memory

What is a Crystallized Memory?

A deterministic, portable capability artifact from crystallization.

What is an Ascended Memory?

A crystallized memory produced through Ascension with dual provenance.

Exports

Can exported capabilities run without CMPSBL?

Yes. Every export includes the Mini Runtime. No network connection needed.

What languages can I export to?

Up to 25, gated by CJPI score tier.

Development

Do I need an SDK?

No. Standard fetch with JSON payloads and Bearer token.

Can I build apps directly on the substrate?

Yes. Apps, chatbots, copilots, agents, and workflows.
