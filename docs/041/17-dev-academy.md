## Purpose

This document describes Dev Academy — the structured learning environment for developers building on the CMPSBL cognitive substrate.

---

## 1. What Is Dev Academy?

Dev Academy is CMPSBL's guided education platform. It provides structured learning paths, hands-on exercises, and progression tracking for developers learning to build on the cognitive substrate.

---

## 2. Who Is It For?

| Audience | Starting Point |
|---|---|
| **New developers** | Fundamentals track |
| **Experienced developers** | Integration track |
| **Team leads** | Architecture track |
| **Researchers** | Discovery track |

---

## 3. How It Fits Into CMPSBL

Dev Academy is designed to bring developers from zero substrate knowledge to production-ready proficiency:

```
Dev Academy (learn) → CodeLab (experiment) → Production (deploy)
```

Academy exercises run on the live substrate, building real familiarity with node capabilities, memory systems, and governance patterns.

---

## 4. Learning Structure

### Warm-Up Sequences

Introductory exercises that progressively introduce substrate capabilities:

1. First intent broadcast
2. Memory storage and recall
3. Semantic search
4. Multi-node intent routing
5. Governance awareness

### Difficulty Tiers

Exercises are organized by difficulty with clear progression:

| Tier | Focus |
|---|---|
| **Foundation** | Core concepts, single-node operations |
| **Integration** | Multi-node chains, memory patterns |
| **Architecture** | System design, orchestration |
| **Advanced** | Discovery, crystallization, export |

### Rollback Drills

Practice safe mutation techniques:

- Propose a system change
- Observe governance gate evaluation
- Practice rollback procedures
- Build confidence with the consent protocol

---

## 5. Progression Tracking

### Micro-Feedback

Every exercise step generates feedback signals:

- Completion status
- Quality assessment
- Time to completion
- Error patterns

### Skill Profiles

The system tracks competency across capability areas:

- Memory operations
- Reasoning integration
- Security awareness
- Orchestration patterns
- Discovery and export

### Stamina Metrics

Sustained performance monitoring helps identify:

- Optimal session duration
- Fatigue patterns
- Knowledge retention rates

---

## 6. What It Produces

| Output | Description |
|---|---|
| **Proficiency profile** | Verified competency scores |
| **Working code** | Tested patterns ready for production |
| **Substrate familiarity** | Hands-on experience with all major nodes |
| **Best practices** | Governance, memory, and security patterns |

---

## 7. Connection to the Substrate

Academy exercises interact with the live substrate. Developers work with real nodes, real memory, and real governance — not simulations.

Exercises are designed to be non-destructive and operate within controlled scopes.
