01 — Core Concepts

Documentation Epoch 041 · Public · Last Updated: 2026-03-16

1. Substrate

The substrate is the foundational cognitive runtime beneath all CMPSBL operations. It is a self-evolving operating system layer between AI models and applications, managing memory, orchestration, governance, and capability execution.

2. Nodes

A node is an autonomous subsystem inside the CMPSBL operating system. Each node represents a specialized system capability. CMPSBL operates a 40-primitive matrix across 4 categories.

3. Resolvers

A resolver is an executable capability owned by a node. Naming convention: node.resolver_name

  • brain.reasoning_context — Contextual reasoning
  • memory.semantic_search — Vector-based memory recall
  • defense.threat_score — Threat evaluation
  • evolution.upgrade_readiness — Mutation readiness check
  • forge.signal_forge — Blueprint synthesis

4. INTENT Routing

The INTENT protocol coordinates all execution. Every action is expressed as an intent, routed to resolvers, and logged with a receipt.

User Action → broadcastIntent() → Intent Router → Resolver Execution → Response → Telemetry

5. Capabilities

A capability is a discrete, invocable function registered in the substrate's capability registry. The substrate maintains 940+ capabilities across its 40-primitive matrix.

6. Memory

Persistent Memory — Long-term storage with vector search, spaced repetition, and contradiction detection.

Memory Stream — The continuous discovery engine that observes system behavior and generates new capabilities.

Crystallized Memory — A deterministic, exportable capability artifact produced through the crystallization process.

Ascended Memory — A class of crystallized memory produced through Ascension cycles involving developer software.

8. Crystallization

Crystallization converts a discovery into a portable, deterministic capability artifact.

Discovery → Sampling → Condensing → Crystallizing → Capability Pack

9. Ascension

Ascension is the process where external developer software enters the substrate and participates in discovery cycles. Resulting capabilities become Ascended Memories.

10. Capability Packs

The complete export artifact: memory chain implementation, Mini Runtime, documentation, license, test bench, build config, and manifest.

11. Mini Runtime

The Mini Runtime™ Engine is a zero-dependency, pure TypeScript in-memory runtime bundled with every capability export.

12. Universal Export Adapter

Software Languages (18): TypeScript, JavaScript, Python, Go, Rust, C, C++, Java, Kotlin, Swift, Ruby, PHP, Lua, Elixir, Scala, Haskell, Zig, Dart

Hardware Description Languages (7): Verilog, VHDL, SystemVerilog, Chisel, SpinalHDL, Amaranth, FIRRTL

13. Mesh Communications

Node-to-node signals powering system observability. Signal categories include acknowledgement, discovery, escalation, processing, completion, warning, and heartbeat.

14. Governance

Server-enforced rules controlling system behavior under a mandatory consent protocol. Modes: ACTIVE, OBSERVE, LOCKDOWN, EVOLVE.

15. CJPI Score

Scores discoveries on four dimensions: Novelty, Utility, Complexity, and Composability. Range: 0–100. Export floor: 68+. Formula is sealed.
