13 — Substrate Development

Documentation Epoch 041 · Public · Last Updated: 2026-03-16

1. Overview

CMPSBL is not only for importing software through Ascension. It is a platform for building software directly on the substrate: 40-primitive matrix, 940+ capabilities, persistent memory, intent routing, governance, telemetry, and exports.

2. What You Can Build

TypeKey Features
Web ApplicationsMemory APIs, BRAIN reasoning, NEXUS routing
ChatbotsPersistent memory, context windowing, confidence
CopilotsTool chains, failure recovery, proficiency gating
AgentsMulti-step orchestration, CORTEX, telemetry
WorkflowsIntent routing, saga orchestration, governance

3. Development Model

API-first via unified gateway. Stateless frontend, stateful substrate. Event-driven via mesh communications.

4. Deployment Patterns

  • Substrate-Hosted — Thin client, full substrate backend
  • Hybrid — Selective substrate capabilities
  • Export and Embed — Discover, crystallize, export standalone
