05 — Capability Export System

Documentation Epoch 041 · Public · Last Updated: 2026-03-16

1. Overview

The Capability Export System transforms crystallized discoveries into portable software packages that run independently of the full substrate.

Every exported capability is fully standalone. No network connection to CMPSBL is required after export.
