06 — Mini Runtime™ Engine

Documentation Epoch 041 · Public · Last Updated: 2026-03-16

1. What Is the Mini Runtime?

A condensed, pure TypeScript in-memory runtime that reproduces substrate capability contracts for exported discoveries to execute independently.

2. Why It Exists

  • No network dependency — Runs offline
  • No substrate account required — End users don't need CMPSBL access
  • Deterministic execution — Same inputs → same outputs
  • Zero external dependencies

3. What It Reproduces

SubsystemDescription
CJPI ScoringQuality scoring contracts
Saga OrchestrationMulti-step transaction coordination with rollback
Finite State MachinesState transition management
Node InterfacesTyped contracts matching substrate signatures
Telemetry StubsNon-operational telemetry interfaces for API compatibility
