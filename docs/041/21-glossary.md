# 21 — Glossary

**Version:** Documentation Epoch 041  
**Classification:** Public  
**Last Updated:** 2026-03-16

## Purpose

Complete terminology reference for the CMPSBL cognitive substrate.

---

| Term | Definition |
|---|---|
| **Apex Discovery** | A discovery scoring 96–100 CJPI. The highest tier. Replaces the deprecated term "Crown Jewel." |
| **Ascended Memory** | A crystallized memory produced through the Ascension process, with dual provenance (developer code + substrate). |
| **Ascension** | The lifecycle where developer software enters the substrate as a Candidate Node and participates in discovery cycles. |
| **Audit Chain** | Hash-linked sequence of operation receipts providing tamper-evident audit trail. |
| **Candidate Node** | Developer software temporarily operating within the substrate during Ascension. |
| **Capability** | A discrete, invocable function registered in the substrate's capability registry. Replaces "Artifact" or "Resolver" in product-facing text. |
| **Capability Pack** | The complete export bundle from crystallization: code, runtime, docs, license, tests, manifest. Replaces "Artifact Pack." |
| **Chain** | A sequence of resolver interactions forming a discovered execution path. Replaces "Pipeline" in product-facing text. |
| **CJPI** | Composable Judgment & Performance Index. Scores discoveries on Novelty, Utility, Complexity, and Composability (0–100). |
| **CLM (Constant Learning Mode)** | The standard for continuous system training and improvement. |
| **CodeLab** | Interactive development environment for exploring and building on the substrate. |
| **Cognitive** | An AI agent identity within a CMPSBL agency, with specializations and competency scores. |
| **Crystallization** | The mechanism converting a discovery into a portable, deterministic capability artifact. |
| **Crystallized Memory** | A deterministic, exportable capability artifact produced through crystallization. The general term; Ascended Memories are a subclass. |
| **Dev Academy** | Structured learning environment with guided exercises and progression tracking. |
| **Discovery** | A high-value finding surfaced by the Memory Stream. Preferred term over "Pipeline" or "Artifact." |
| **Discovery Engine** | The Memory Stream's pattern recognition and scoring system. |
| **Engine** | A composable processing unit within the substrate. 54 engines across 4 tiers (META, APEX, ELITE, CORE). |
| **EVOLUTION** | The canonical node for system modernization, mutation, and runtime evolution. |
| **Foundry** | The exploration engine that discovers new capabilities by testing node/resolver combinations. |
| **Governance** | Server-enforced rules controlling system behavior. Modes: ACTIVE, OBSERVE, LOCKDOWN, EVOLVE. |
| **INTENT** | The routing protocol coordinating all system execution. Every action is an intent. |
| **Memory** | In CMPSBL context: persistent cognitive storage with vector search, contradiction detection, and tier management. Replaces "Pipeline" in product text. |
| **Memory Stream** | The system's continuous discovery engine. Observes behavior, scores findings, crystallizes capabilities. |
| **Mesh Communications** | Node-to-node signals powering observability. Persisted and translated into readable dialogue. |
| **Mini Runtime™** | Zero-dependency TypeScript runtime bundled with exports, reproducing required substrate contracts. |
| **Mint** | Discovery tier for CJPI 68–79. Quality baseline for export eligibility. |
| **Mutual Moat** | The structural dependency pattern in Ascended Memories, creating mutual value between developer and substrate. |
| **Mythic** | Discovery tier for CJPI 94–95. Exceptional quality. |
| **Node** | An autonomous subsystem inside the substrate. 40 nodes across 12 sectors. Replaces "module" in product text. |
| **Prime** | Discovery tier for CJPI 80–89. High quality, broadly useful. |
| **Raw** | Discovery tier for CJPI below 68. Below export threshold. |
| **Receipt** | A tamper-evident audit record of an intent execution. |
| **Relic** | Discovery tier for CJPI 90–93. Premium, production-grade. |
| **Resolver** | An executable capability owned by a node. Named as `node.resolver_name`. |
| **Safety Switch** | Emergency isolation mechanism. Replaces "Circuit Breaker." |
| **SEBA Pipeline** | The 7-gate promotion pipeline for system mutations: Lint → Test → Review → Stage → Consent → Deploy → Prod. |
| **Signal Forge** | Blueprint synthesis engine within the FORGE node. Produces CJPI-validated architecture designs. |
| **Substrate** | The foundational cognitive runtime beneath all CMPSBL operations. |
| **Tier** | Quality classification for discoveries: Apex, Mythic, Relic, Prime, Mint, Raw. |
| **Universal Export Adapter** | System generating capability exports across 18 software languages and 7 HDL targets. |

### Deprecated Terms

| Deprecated | Replacement |
|---|---|
| Artifact | Capability or Discovery |
| Artifact Pack | Capability Pack |
| Circuit Breaker | Safety Switch |
| Continuous Learning Mode | Constant Learning Mode (CLM) |
| Crown Jewel | Apex Discovery |
| Module | Node |
| Auxiliary Node | Ascension |
| Pipeline | Memory or Chain |
