02 — How CMPSBL Works

Documentation Epoch 041 · Public · Last Updated: 2026-03-16

1. Overview

CMPSBL is a cognitive operating system composed of 40 autonomous nodes across 4 categories providing intent-based execution, persistent memory, autonomous discovery, governed mutation, and portable exports.

2. Execution Model

User or System Action
    ↓
broadcastIntent({ intentType, sourceModule, input })
    ↓
Intent Router → Resolver Selection & Execution
    ↓
Response Aggregation → Mesh Communication Events → Telemetry & Audit

4. Memory Stream

System Activity → Behavior Signals → Pattern Recognition → CJPI Scoring → Tier Classification → Crystallization (≥ 68) → Capability Pack

5. Crystallization

  1. Sampling — Execution path isolated, node interactions recorded
  2. Condensing — Dependencies resolved, execution graph compressed
  3. Crystallizing — Final artifact generated with all runtime requirements

6. Ascension

  1. INGEST — Developer software introduced and analyzed
  2. ASCENSION — Software runs as Candidate Primitive through discovery cycles
  3. CRYSTALLIZATION — Successful chains scoring ≥ 68 CJPI crystallized
  4. ASCENDED MEMORY — Resulting artifacts available for export

8. Governance

Lint → Test → Review → Stage → Consent → Deploy → Prod

Every gate must pass. The consent gate requires explicit user approval.

9. Telemetry

Telemetry is always non-blocking. Key surfaces: Intent Mesh, Node Health, Memory Stream, Resolver Activity.
