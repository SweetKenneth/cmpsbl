# 02 — How It Works

---

## The Architecture (Simplified)

CMPSBL is built from **40 specialized modules** organized into layers:

```
🛡️ DEFENSE (Security Shell — protects everything)
  📋 GOVERNANCE (Supervisory Plane — approves every action)
    🧠 BRAIN, MEMORY, DREAM (Cognitive Core — reasoning & learning)
      ⚙️ 10 Execution Modules (AI capabilities — routing, generation, orchestration)
        🔒 Expansion Zones (Ethics, prediction, manufacturing, evolution)
```

### What Each Layer Does

| Layer | Modules | Purpose |
|-------|---------|---------|
| **Spine** | CORE, SYSTEM, BRAIN, MEMORY, DREAM | The kernel — boots, reasons, remembers, synthesizes |
| **Compliance Grid** | ACCESS, IDENTITY, AUDIT, NERVE, RELAY, RIPPLE | Enforces rules, manages auth, routes events |
| **Execution** | DECODE, ENCODE, NEXUS, CORTEX, VISION + 5 more | The AI capabilities you interact with |
| **Expansion** | 10 modules across 3 zones | Ethics, prediction, simulation, manufacturing |
| **Covert** | EVOLUTION, SHADOW, PHANTOM | Self-improvement, testing, privacy |
| **Governance** | GOVERNANCE, DEFENSE, IMMUNITY, INTENT | Supervision, security, cross-cutting intelligence |

---

## How Requests Flow

1. Your request arrives at **DEFENSE** — threat assessment
2. **NEXUS** routes it to the best AI provider and model
3. The right **Execution module** processes it (DECODE for language, ENCODE for code, etc.)
4. **BRAIN** and **MEMORY** provide reasoning and context
5. **AUDIT** logs everything
6. Response returns through **DEFENSE** back to you

Every step is governed, audited, and observable.

---

## Health & Reliability

Each of the 40 primitives has its own **circuit breaker**. If one primitive has problems:
- It isolates automatically
- The rest of the system continues working
- Auto-healing attempts to restore it
- You're notified if manual intervention is needed

System health is a **deterministic score** — a weighted sum of all 40 primitives, not a guess.

---

## Memory & Learning

CMPSBL remembers across sessions through a 4-tier memory system:

| Tier | Speed | What's Stored |
|------|-------|--------------|
| **Hot** | Instant | Active session context |
| **Warm** | Fast | Recent tasks and learning |
| **Cold** | Standard | Historical data and completed work |
| **Glacier** | Archive | Long-term retention |

Knowledge moves between tiers automatically based on usage patterns. The system also runs **Constant Learning Mode (CLM)** — continuously processing topics and compounding knowledge.

---

## Evolution

The system improves itself through a validated pipeline:
1. Changes are proposed (by the system or operators)
2. **Shadow runs** test changes against real inputs in isolation
3. **7 validation gates** must pass (including truth preservation)
4. Only then does the change reach production
5. If anything goes wrong, **automatic rollback** activates

No untested change ever reaches production.
