## Sales Playbook

### Discovery Questions

1. **Current State**
   - "How are you currently building AI applications?"
   - "What AI providers are you using?"
   - "How do you handle memory/state?"

2. **Pain Points**
   - "What's your biggest challenge with AI infrastructure?"
   - "How do you ensure AI decisions are auditable?"
   - "What happens when your AI provider has an outage?"

3. **Requirements**
   - "Do you need persistent memory across sessions?"
   - "What compliance requirements do you have?"
   - "How important is vendor independence?"

### Objection Handling

**"We can build this ourselves"**
> "You absolutely could. The question is whether you should. Building persistent memory, multi-provider routing, security, and observability typically takes 6-12 months. With promptfluid®, you're building on that foundation in days."

**"We're already using [LangChain/etc.]"**
> "LangChain is great for prototyping. promptfluid® is infrastructure. You can use both—LangChain for orchestration patterns, promptfluid® for the execution substrate beneath it."

**"Why not just use OpenAI Assistants?"**
> "If OpenAI is your only provider forever and you don't need full control over memory, Assistants works. If you want provider flexibility, self-hosting options, or custom security—you need a substrate."

**"It's open source, why would we pay?"**
> "The code is free. Running production infrastructure isn't. Managed deployment means we handle scaling, updates, security patches, and support. Enterprise licensing adds compliance, training, and dedicated engineering."

## Competitive Intelligence

### LangChain
- Framework focus, not infrastructure
- Requires extensive custom code for production
- No built-in persistence or security
- Community large but fragmented

### LlamaIndex
- RAG-focused, not general cognition
- Indexing strength, execution weakness
- No security layer
- Self-host only

### OpenAI Assistants
- Vendor lock-in to OpenAI
- Limited memory control
- No self-hosting
- Black box execution

### Anthropic Claude
- Single-model, not multi-provider
- No persistent memory
- No infrastructure layer
- API only
