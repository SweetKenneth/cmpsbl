# FUNCTIONS — 03 Platform Utilities

## Utility Families

- Feature flags and overrides
- Circuit breaker controls
- Health scorecard
- Cascade detection hooks
- Persistence and restore controls
- Infrastructure primitives (bloom, queue, semaphore, saga, state machine)

## SEO Utility Surface

- route-to-SEO resolution
- page metadata retrieval

## Usage Principle

Utilities should be composed behind module boundaries, not called ad hoc from unrelated UI surfaces.
