Tiered Cognitive Memory with Spaced Repetition

SM-2 Integration for Persistent AI Knowledge Management

Kenneth E. Sweet Jr. · ORCID: 0009-0001-4237-1243
PromptFluid® · CMPSBL.com
DOI: 10.5281/zenodo.18234909

Abstract. We present a tiered cognitive memory architecture for AI systems that integrates the SM-2 spaced repetition algorithm — originally developed for human learning optimization — into the memory retrieval and reinforcement pipeline. The architecture implements three memory tiers (hot, warm, cold) with automatic promotion/demotion based on a unified salience scoring function. Memories that are recalled gain reinforcement; memories that decay lose salience, mimicking the biological dynamics of human long-term memory formation.
Disclaimer: The designation "novel integration" reflects the author's assessment based on comprehensive review of publicly available AI systems literature as of February 2026. The author welcomes identification of prior art.

1. The Memory Problem in AI

Current AI systems operate in one of two modes:

  • Stateless — No memory across sessions. Each interaction begins from zero context. This is the default for all major LLM platforms.
  • Flat storage — Simple key-value or vector stores that accumulate knowledge without degradation, prioritization, or reinforcement. This leads to unbounded growth and retrieval noise.

Neither approach models the sophistication of biological memory, where important, frequently-accessed memories are strengthened while irrelevant information naturally decays.

3. Unified Salience Function

All memory retrieval and tier management operates through a single authoritative scoring function:

S(m) = Σᵢ wᵢ · fᵢ(m) where i ∈ {1..8}, Σwᵢ = 1.0 Factors include: source confidence, temporal recency, access frequency, SM-2 reinforcement signal, cross-module consensus, type importance, attention focus, and query relevance.

The specific factor weights and decay parameters are proprietary. The structural commitment is that all subsystems use this single function — eliminating scoring inconsistencies across retrieval pathways.

4. SM-2 Integration

The SuperMemo SM-2 algorithm, originally designed to optimize human flashcard review intervals, is adapted for AI memory reinforcement. When a memory is recalled:

  • Its reinforcement signal (f₄) increases based on recall quality
  • Its next review interval extends (successful recall → longer intervals)
  • Poor-quality recalls trigger shorter intervals and potential tier demotion

This creates a cognitive rehearsal effect: knowledge that is actively used becomes more accessible, while knowledge that is never recalled naturally decays through tier boundaries.

5. Noise Prevention

The memory system implements ingestion filters to prevent low-quality data from entering the knowledge base:

  • Minimum content length requirements
  • Alphanumeric ratio thresholds (reject noise-heavy content)
  • Repetition detection (reject content with excessive repeated patterns)
  • Automatic degradation of stale memories (untouched for configurable periods)

6. Prior Art Assessment

Vector databases (Pinecone, Weaviate) provide similarity-based retrieval but lack tiered management, reinforcement dynamics, or decay mechanisms. Cognitive architectures (ACT-R) model memory decay theoretically but are not deployed in production AI systems. The integration of SM-2 spaced repetition into an AI cognitive memory system appears to be novel.

7. Significance

Tiered cognitive memory transforms AI from a system that accumulates knowledge without discrimination into one that actively manages its knowledge base — strengthening valuable memories, degrading irrelevant ones, and maintaining retrieval quality over time.
