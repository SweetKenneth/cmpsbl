Multi-Agent Dream Pooling with Consent Gating

Privacy-Preserving Collective Intelligence for Cognitive Agent Networks

Kenneth E. Sweet Jr. · ORCID: 0009-0001-4237-1243
PromptFluid® · CMPSBL.com
DOI: 10.5281/zenodo.18234909

Abstract. We present a collective intelligence mechanism for multi-agent AI systems where agents share learned insights through a consent-gated dreaming process. Three pooling modes — isolated, shared, and collective — enable configurable privacy/intelligence tradeoffs. Participation requires explicit consent with domain-level exclusion lists, enforced at the infrastructure level through row-level security policies. To our knowledge, this is the first multi-agent system implementing offline collective learning with privacy-preserving consent gates.

1. The Multi-Agent Knowledge Problem

Multi-agent AI frameworks (CrewAI, AutoGen, LangGraph) enable task delegation and coordination between agents. However, these systems lack mechanisms for agents to learn from each other's experiences autonomously. Knowledge gained by one agent during task execution is not transferred to other agents unless explicitly programmed.

2. Three Pooling Modes

ModeScopePrivacy LevelUse Case
IsolatedEach agent dreams independentlyFull isolation — no knowledge sharingSensitive domains, compliance requirements
SharedDream synthesis outputs shared across the agencyOutput-only sharing — raw memories remain privateTeam learning with privacy preservation
CollectiveJoint working set drawn from all agentsFull memory access within the agencyMaximum collective intelligence

3. Consent Architecture

Pool participation is governed by an explicit consent framework:

  • Opt-in requirement — No agent participates in shared or collective dreaming without explicit consent
  • Domain exclusion — Agents can exclude specific knowledge domains from pooling while participating in others
  • Infrastructure enforcement — Consent policies are enforced at the database level through row-level security, not through application-level checks that could be bypassed
  • Revocability — Consent can be revoked at any time; shared knowledge is not retroactively recalled but no new sharing occurs

4. Collective Synthesis

In collective mode, the dream synthesis phase operates on a combined working set from all participating agents. This enables pattern detection across agent boundaries — discovering connections between one agent's security observations and another agent's performance data, for example. These cross-agent syntheses represent emergent collective intelligence that no individual agent could achieve alone.

5. Prior Art Assessment

Federated learning (McMahan et al., 2017) shares model updates across participants but operates on gradient aggregation, not cognitive knowledge synthesis. Multi-agent systems (CrewAI, AutoGen) share task results but lack offline collective learning with consent gating. The combination of dream-state synthesis with privacy-preserving consent architecture appears to be novel.

6. Significance

Dream pooling enables multi-agent systems to develop collective intelligence while respecting per-agent privacy boundaries. This is particularly relevant for enterprise deployments where different agents handle different levels of data sensitivity but would benefit from shared learning outcomes.
