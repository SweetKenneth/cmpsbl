Epistemic Conversation Architecture

Transparent Knowledge Classification in AI Discourse

Kenneth E. Sweet Jr. · ORCID: 0009-0001-4237-1243
PromptFluid® · CMPSBL.com
DOI: 10.5281/zenodo.18234909

Abstract. We present an epistemic conversation architecture where an AI system formally classifies its own knowledge state within every response — distinguishing between verified knowledge, inferred conclusions, and speculative hypotheses. Unlike conventional LLM uncertainty expressions ("I think," "I'm not sure"), this classification is linked to a persistent confidence-scored memory system, providing structurally honest intellectual transparency in AI discourse.
Disclaimer: The designation "novel contribution" reflects the author's assessment based on comprehensive review of publicly available AI systems literature and commercial platforms as of February 2026. The author welcomes identification of prior art.

1. The Epistemic Opacity Problem

Large language models produce fluent, confident-sounding text regardless of the reliability of their underlying knowledge. When an LLM says "I think" or hedges with qualifiers, these expressions are stylistic — they do not reflect a formal assessment of knowledge certainty. Users have no way to distinguish between a statement backed by high-confidence, frequently-reinforced memory and a statement that is essentially generated speculation.

2. The DECODE Classification System

The DECODE module implements three epistemic markers that classify every substantive statement:

VERIFIED

Statement is sourced from high-confidence memories that have been reinforced through spaced repetition, corroborated across multiple sources, or directly observed through system telemetry. The system can point to the specific memory records supporting this claim.

INFERRED

Statement is derived from pattern analysis across multiple memories. The conclusion is logical given available evidence but has not been directly verified. The system can identify the evidence chain and its confidence level.

NARRATIVE

Statement is speculative, hypothetical, or generated for explanatory purposes. The system explicitly acknowledges that this content is not backed by verified or inferred evidence. Used for brainstorming, creative synthesis, and exploratory discourse.

3. Integration with Cognitive Memory

The epistemic classification is not a standalone feature — it is structurally linked to the substrate's tiered memory system. When DECODE classifies a statement as VERIFIED, it references specific memory records with quantified confidence scores, access frequency, and reinforcement history. This creates an auditable chain from output statement to supporting evidence.

4. Truth Verification Engine

A validation layer ensures that all system interfaces — dashboard, terminal, module voice, and API responses — remain synchronized with verified telemetry. Metrics displayed to users must reflect actual measured values, not estimated or projected figures. When data is unavailable, the system states this explicitly rather than generating plausible-sounding numbers.

5. Prior Art Assessment

LLM-based systems may express uncertainty colloquially ("I'm not confident about this") but lack:

  • Formal epistemic classification linked to scored memory
  • Auditable evidence chains from statement to supporting data
  • Structural distinction between inference and speculation
  • System-wide enforcement of honest telemetry reporting

6. Significance

Epistemic conversation addresses a fundamental trust problem in AI: users cannot currently distinguish between reliable and unreliable AI output. By making knowledge classification structural rather than stylistic, the system provides a foundation for AI-human collaboration where trust is earned through demonstrated intellectual honesty, not assumed through fluent language.
