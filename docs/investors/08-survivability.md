# 08 — Survivability & Continuity

**Classification:** CONFIDENTIAL — Investor Use

---

## 1. The Key Question

**What happens if the founder is unavailable?**

Answer: The system continues operating. Decisions requiring human approval are queued, not rejected. Automated operations (CLM, ENGINEER, Ironclad, NEXUS failover) continue without interruption.

---

## 2. Dead-Man Switch

If the primary credential holder is unreachable for 30 consecutive days:
1. Designated successor receives sealed credential package
2. Identity verification via pre-registered method
3. All access logged in AUDIT
4. Governance continuity procedures activate

## 4. Minimum Viable Operation

The substrate operates with:
- One PostgreSQL instance
- One Deno edge runtime
- One AI provider API key
- One operator with admin credentials

No external dependencies beyond the above. Standard, commodity infrastructure.
