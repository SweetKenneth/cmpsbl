## Issues Found & Fixes Applied

### 1. Correlation-ID activeContexts Unbounded Map (MEDIUM)
- **File:** `src/lib/substrate/correlation-id/index.ts`
- **Severity:** Medium — unbounded Map grows without limit under sustained load
- **Issue:** `activeContexts` Map had no cap; could grow indefinitely in long-running sessions
- **Fix:** Added `MAX_CONTEXTS = 2000` cap with FIFO eviction of oldest context when exceeded
- **Validation:** All 11 correlation-id tests pass
- **Rollback:** Remove the cap check in `createContext()`

### 2. Correlation-ID Spans Eviction O(n) Splice (LOW)
- **File:** `src/lib/substrate/correlation-id/index.ts`
- **Severity:** Low — `splice(0, n)` is O(n) on every eviction
- **Issue:** When spans exceeded MAX_SPANS, `splice(0, 30%)` shifted all remaining elements
- **Fix:** Replaced with `copyWithin(0, evictCount)` + `length` truncation — same semantics, O(n) but with lower constant factor (native memcpy)
- **Validation:** All correlation-id tests pass
- **Rollback:** Revert to `splice(0, Math.floor(MAX_SPANS * 0.3))`

### 3. Request Coalescer Stuck Promise Leak (HIGH)
- **File:** `src/lib/substrate/request-coalescer.ts`
- **Severity:** High — stuck/hanging promises permanently occupy the inflight Map
- **Issue:** If an executor promise never resolves or rejects (e.g., hung fetch without timeout), the Map entry persists forever, blocking all future identical requests
- **Fix:** Added `inflightTimestamps` Map + 60s TTL safety net. Stale entries are evicted on next access to the same key
- **Validation:** Build succeeds, all tests pass
- **Rollback:** Remove `inflightTimestamps` Map and TTL check

- **Trace system:** UUID v4 trace IDs, span tracking, parent-child relationships — well-structured
- **Telemetry sampler:** Probabilistic sampling with burst detection (50 events/5s window). Error/critical/warn always pass through.
- **Structured logging:** `log.info/warn/error` with module tags throughout substrate

### Performance & Scaling
- **Telemetry aggregator:** Paginated AI queries (5 pages × 1000 rows cap). Uses `Promise.allSettled` for parallel queries — good pattern.
- **Cron runner:** Singleton with `running` Set preventing concurrent execution of same job. History capped at 200 entries.
- **Request coalescer:** Deduplicates identical in-flight requests — good for reducing redundant API calls
