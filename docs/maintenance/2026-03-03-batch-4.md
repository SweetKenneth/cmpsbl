## Issues Found & Fixes Applied

### 1. RLS Data Leak — nexus_provider_health & nexus_cost_ledger (HIGH)
- **Tables:** `nexus_provider_health`, `nexus_cost_ledger`
- **Severity:** HIGH — internal service tables were readable by anon users
- **Issue:** "Service role full access" policy used `roles={public}` instead of `service_role`, granting ALL operations to ALL roles including anon
- **Fix:** Dropped and recreated policies with `TO service_role` restriction
- **Validation:** RLS tests confirm anon now gets empty results
- **Rollback:** Recreate policies with `TO public` (not recommended)

### 2. Missing DB Retention Policies (MEDIUM)
- **Severity:** Medium — 8 high-growth tables had no cleanup mechanism
- **Fix:** Created `cleanup_retention()` function covering:
  - `brain_events`: 90 days (largest table at 110MB/184K rows)
  - `ai_usage_log`: 90 days
  - `access_usage`: 90 days
  - `nexus_traces`: 30 days
  - `nexus_cost_ledger`: 180 days (financial — longer retention)
  - `agency_task_logs`: 60 days
  - `agency_api_calls`: 60 days
  - `audit_logs`: 365 days (compliance)
  - `agency_agent_telemetry`: 90 days
  - `ip_reputation`: 30 days (stale IPs)
- **Validation:** Function executes successfully, returns per-table delete counts

### 3. Missing Operational Monitoring Functions (LOW)
- **Fix:** Created `detect_stale_scheduled_tasks()` — finds active tasks with `next_run_at` in the past
- **Fix:** Created `detect_orphan_records()` — scans 7 FK relationships for orphaned rows
- **Validation:** Both functions return clean results (0 orphans, 0 stale tasks)

### 4. Missing Edge Function Tests (MEDIUM)
- **Severity:** Medium — zero automated tests for critical edge functions
- **Fix:** Created 17 Deno tests across 3 critical functions:
  - `dream-feeder-api`: 7 tests (CORS, input validation, XSS, payload limits, method rejection)
  - `pf-nexus-router`: 4 tests (CORS, empty body, missing fields, response contract)
  - `pf-substrate`: 6 tests (CORS, empty body, health, SQLi, path traversal, stack trace leaks)
- **Validation:** All 17 tests pass

### 5. Missing RLS Policy Tests (MEDIUM)
- **Fix:** Created 11 RLS validation tests in `_shared/rls-validation.test.ts`:
  - 3 anon SELECT tests (user_roles, activations, audit_log → must return empty)
  - 3 anon INSERT tests (user_roles, audit_logs, evolution_runs → must reject)
  - 3 service-only table tests (nexus_provider_health, nexus_cost_ledger, governance_mode)
  - 2 public table tests (agency_templates, discoveries → must allow)
- **Validation:** All 11 tests pass (after RLS fix in #1)

### 6. Vitest/Deno Test Isolation (LOW)
