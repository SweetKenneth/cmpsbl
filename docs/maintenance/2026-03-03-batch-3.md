## Issues Found & Fixes Applied

### 1. Tenant Isolator Unbounded Map (MEDIUM)
- **File:** `src/lib/substrate/tenant-isolator.ts`
- **Severity:** Medium — `tenants` Map grows without limit
- **Issue:** Every unique tenant ID creates a permanent entry. Under sustained multi-tenant load, this Map grows indefinitely
- **Fix:** Added `MAX_TENANTS = 500` cap with LRU-style eviction of oldest inactive tenant (active=0) when exceeded
- **Validation:** Build succeeds, all 120+ tests pass
- **Rollback:** Remove the cap check in `ensureTenant()`

### 2. Quota Enforcement usageMeters Unbounded Map (MEDIUM)
- **File:** `src/lib/access/quotaEnforcement.ts`
- **Severity:** Medium — `usageMeters` Map grows per-developer without cap
- **Issue:** Each unique `developerId:resourceType` pair creates a meter entry that persists even after period expiry
- **Fix:** Added `MAX_METERS = 2000` cap. On overflow, expired meters are evicted first, then FIFO eviction as fallback
- **Validation:** Build succeeds, all tests pass
- **Rollback:** Remove `MAX_METERS` and the eviction block in `recordUsage()`
