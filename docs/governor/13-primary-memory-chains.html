Primary Memory Chains enable coordinated multi-node responses across the substrate. When a trigger condition is met, a predefined sequence of node actions fires automatically — each stage transforming and forwarding its payload to the next.
  • Declarative — stages, triggers, and conditions defined upfront
  • Tracked — EMA-weighted success rate, duration, confidence
  • Governed — GOVERNANCE can pause or override any chain
  • Audited — every execution logged with tamper-evident receipts
