## Purpose

This is the **public research deposit** for CMPSBL® — Governed Cognitive Infrastructure. It supersedes the v13.5 Zenodo deposit (April 2025) and reflects the SYMBIOTIC epoch architecture as of April 2026.

This library is intentionally **non-reconstructive**: it documents **what** the substrate is and **why** it works, but deliberately omits internal heuristics, scoring weights, dispatch internals, and engine implementation details that would enable copying. Researchers, evaluators, and policy analysts will find enough to reason about the system. Operators must use the substrate itself.

## What Is Deliberately Omitted

The following are **not** included in this deposit and will not be made public:

- CJPI scoring weight values (only the four-factor structure is disclosed)
- FNV-1a fingerprint salts and rotation epoch values
- Lex governance rule priorities and conflict-resolution details
- DREAM combinatorial scoring weights and pruning thresholds
- Memory Stream discovery cycle internals beyond the 8-hour interval
- Convex Core™ dispatch matrix construction algorithm
- Ascension collision sequence ordering
- Engine-level implementation source

Researchers requiring deeper access can contact the author. Independent reproduction of the substrate from this deposit alone is not possible by design.
