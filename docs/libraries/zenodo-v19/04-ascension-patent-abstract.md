# 04 — Ascension™ Patent Abstract

**Zenodo v19 · SYMBIOTIC Epoch**
**U.S. Provisional Application No. 64/029,678**

---

## Public Abstract

Ascension™ is a deterministic software evolution method that identifies, scores, and hardens latent architectural capabilities in arbitrary source code without invoking external artificial intelligence. The method operates by colliding uploaded code against a fixed matrix of 40 computational primitives organized across four taxonomic categories (Organs, Layers, Engines, Agents), scoring emergent combinations via the Crown Jewel Pipeline Index™ (CJPI), and exporting hardened artifacts as self-contained Convex Core™ artifacts.

---

## What Is Claimed (Public)

1. **A deterministic collision method** — input source code is structurally analyzed against a fixed 40-primitive matrix to surface architectural capabilities that the original author did not name.
2. **A four-factor scoring index (CJPI)** — discovered capabilities are scored along four axes: Novelty, Utility, Complexity, Composability. The four-factor structure is disclosed; the weight distribution is not.
3. **A primitive identity fingerprint** — discovered capabilities receive a deterministic identity derived from the primitives they collided against. The fact that FNV-1a-family hashing is used is disclosed; the salts and epoch rotation are not.
4. **An export format** — discovered capabilities ship as self-contained Convex Core™ artifacts that can run independently of the originating substrate.

---

## What Ascension™ Is Not

- It is not generative. No new code is synthesized. Existing structural relationships are surfaced and certified.
- It is not AI-assisted. The pipeline contains no LLM call.
- It is not heuristic. The output for a given input and substrate state is deterministic.

---

## Why This Is Defensible

The novelty is the **collision pipeline as a method**: taking arbitrary code and structurally evaluating it against a fixed governance matrix to produce a fingerprinted, certified artifact. The pipeline is method-claim territory. The 40-primitive matrix is an architectural choice that makes the method tractable.

A competitor who reads this abstract can build a worse system that scores against a different matrix with different factors. They cannot replicate the specific collision pipeline disclosed in the full provisional.
