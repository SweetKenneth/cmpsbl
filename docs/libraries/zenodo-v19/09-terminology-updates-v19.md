# 09 — Terminology Updates v19

**Zenodo v19 · SYMBIOTIC Epoch**

---

## Purpose

The v19 release brings public terminology into alignment with what the substrate **actually does**. Earlier framings ("cognitive substrate," "BRAIN thinks," "autonomous agents," "self-healing") were aspirational in places where the substrate is in fact infrastructural. This document records the terminology updates so prior published material can be re-read against the v19 standard.

The updates are **not** a retraction of capability. The substrate is exactly as capable in v19 as it was in v13.5. The framing is more honest, which makes the claims more defensible.

---

## Term Updates

| Prior Public Term (v13.5 era) | v19 Public Term | Reason for Update |
|---|---|---|
| Cognitive substrate (as system noun) | Governed cognitive infrastructure | The substrate **governs** cognition; it does not perform cognition itself. |
| BRAIN thinks / BRAIN reasons | BRAIN remembers and links | BRAIN is a memory + edge graph + crystal store. It does not infer. |
| Autonomous agents | Policy-governed AI workers | The autonomy is in scheduling and governance. The reasoning step is delegated through NEXUS to external models. |
| Self-healing (as a top-level claim) | Self-healing pipeline (in training) | The Shadow → Simulation → Production pipeline is real. Fully autonomous remediation is in training. |
| EVOLUTION writes patches | EVOLUTION proposes patches (autonomous application in training) | Patch proposal works. Live autonomous application is conservative. |
| Cognitive runtime | Governed runtime | "Cognitive" implies the runtime thinks; it does not. |
