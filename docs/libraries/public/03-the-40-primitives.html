How Primitives Work Together

Primitives don't operate in isolation. The standard execution flow is:

Layers (protect) → Organs (process) → Engines (orchestrate) → Agents (execute)

Automated coordination happens through memory chains — predefined multi-primitive reaction workflows (100 active chains across 9 categories).

Health Scoring

Each primitive contributes to the substrate's overall health score through weighted contribution:

  • Total weight: Σ = 1.000 across all 40 primitives
  • Healthy range: System score ≥ 80
  • Deterministic: Health is a mathematical sum, not an estimate

If any primitive degrades, the system identifies it precisely and routes healing accordingly.
