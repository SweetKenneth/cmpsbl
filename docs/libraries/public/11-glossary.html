Core Terminology

TermDefinition
SubstrateThe CMPSBL cognitive runtime — the complete 40-primitive operating system
PrimitiveOne of 40 specialized components in the substrate (replaces "node" or "module")
CategoryOne of four primitive classifications: Organs, Layers, Engines, Agents (replaces "sector")
Memory ChainAn automated multi-primitive reaction workflow (replaces "pipeline")
OrganA primitive category for internal infrastructure (CORE, BRAIN, MEMORY, etc.)
LayerA primitive category for ambient overlays (DEFENSE, IMMUNITY, GOVERNANCE, etc.)
EngineA primitive category for processing powerhouses (DREAM, CORTEX, NEXUS, etc.)
AgentA primitive category for autonomous actors (DECODE, ENCODE, VISION, etc.)
