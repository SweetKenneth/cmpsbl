# Ascension Engine

---

## What Is Ascension?

Ascension is CMPSBL's **software evolution engine**. Upload any working code — in any language — and the substrate's 40-primitive matrix tests, analyzes, and augments it into enhanced capabilities. The original code is preserved and runs first. CMPSBL wraps around it, adding intelligence, observability, and portability without changing a single line of the original logic.

---

## How It Works

### 1. Upload

Upload a source file (any of 25 supported languages). The Ascension Engine accepts it as a first-class participant in the substrate's discovery process.

### 2. Discovery

The 40-primitive matrix tests the uploaded code. Each primitive asks: "Does this code's behavior combine meaningfully with my capabilities?" Successful combinations are scored and recorded.

### 3. Crystallization

Discoveries that match real architectural patterns become **portable capabilities** — exportable software that combines the original code with the substrate's intelligence layer.

### 4. Export

Export as a ZIP archive containing:

1. **Original source code** — untouched
2. **Mini-Runtime Engine** — standalone execution environment
3. **Cognitive layer** — the substrate's augmentations
4. **Documentation** — auto-generated
5. **Test bench** — validation harness

If CMPSBL disappeared tomorrow, the export still runs. That's the portability guarantee.

## Discovery Scoring (CJPI)

Every discovery receives a **Crown Jewel Pipeline Index** score based on:

| Factor | Weight |
|--------|--------|
| Novelty | How unique is this combination? |
| Utility | How practical is the result? |
| Complexity | How sophisticated is the interaction? |
| Composability | Can this be combined with other discoveries? |

High-scoring discoveries are automatically promoted. The highest-tier discoveries are curated by the system governor.
