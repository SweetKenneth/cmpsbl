# Agent Marketplace

---

## What Are Cognitive Agents?

Cognitive agents are **specialized AI workers** that run inside CMPSBL. Each agent has unique capabilities (called "Crown Jewel powers"), runs in a sealed secure environment, and can improve itself through DREAM Engine synthesis — autonomous learning cycles.

---

## How Agents Work

1. **Browse** the marketplace and choose agents for your needs
2. **Purchase** — one-time payment, perpetual ownership
3. **Deploy** into your agency framework
4. **Assign tasks** — agents work autonomously within their capabilities
5. **Self-improve** — DREAM Engine synthesis helps agents get better over time

## Agency Framework

Agents work together in **agencies** — coordinated teams with:

- Task assignment and progress tracking
- Shared learning via consent-gated DREAM Engine pools
- Economic tracking (cost per task, ROI measurement)
- Scheduled automation for recurring tasks
- Deliverable management and email dispatch

---

## Security Guarantees

- Agents **cannot** access data outside their designated powers
- Agent memory is **isolated** per agency
- Source code is **blocked** — no reverse engineering
- DREAM Engine sharing requires **explicit consent**
- Every agent action is **audited**
