# Glossary

---

## Core Terminology

| Term | Definition |
|------|-----------|
| **Substrate** | The CMPSBL cognitive runtime — the complete 40-primitive operating system |
| **Primitive** | One of 40 specialized components in the substrate (replaces "node" or "module") |
| **Category** | One of four primitive classifications: Organs, Layers, Engines, Agents (replaces "sector") |
| **Memory Chain** | An automated multi-primitive reaction workflow (replaces "pipeline") |
| **Organ** | A primitive category for internal infrastructure (CORE, BRAIN, MEMORY, etc.) |
| **Layer** | A primitive category for ambient overlays (DEFENSE, IMMUNITY, GOVERNANCE, etc.) |
| **Engine** | A primitive category for processing powerhouses (DREAM, CORTEX, NEXUS, etc.) |
| **Agent** | A primitive category for autonomous actors (DECODE, ENCODE, VISION, etc.) |

---

## Architecture

| Term | Definition |
|------|-----------|
| **BYOK** | Bring Your Own Keys — operators supply their own API keys and own their data |
| **Circuit Breaker** | Isolation mechanism that prevents a failing primitive from affecting others |
| **Crown Jewel** | One of 54 classified high-value capabilities restricted to governor-only access |
| **Epoch** | A major version era defined by a thematic milestone |
| **Weighted Matrix** | The health scoring system where each primitive contributes proportionally |
| **Zone Shielding** | Independent circuit breakers per category ensuring graceful degradation |

---

## Memory & Learning

| Term | Definition |
|------|-----------|
| **CLM (Constant Learning Mode)** | The always-on learning engine — up to 14,400 cycles/day |
| **CJPI** | Crown Jewel Pipeline Index — discovery scoring metric |
| **DREAM Engine Synthesis** | Autonomous heuristic generation and self-improvement |
| **Memory Stream** | The substrate's discovery engine — observes behavior, discovers capabilities |
| **Memory Tier** | One of four storage levels: Hot, Warm, Cold, Glacier |

## Evolution & Governance

| Term | Definition |
|------|-----------|
| **SEBA** | Shadow-Evaluated Behavioral Assessment — the 7-gate evolution pipeline |
| **TSAC** | Truth Shadow Arbitration Check — ensures evolution preserves system truth |
| **ADA** | Autonomous Decision Authority — scoped, per-primitive decision-making |
| **Governance Mode** | One of four operating states: Active, Observe, Lockdown, Evolve |
| **Ironclad** | The multi-layer rate limiting and resilience fabric |
| **Shadow Run** | An isolated test of proposed changes against real inputs |

## Agents & Commerce

| Term | Definition |
|------|-----------|
| **Cognitive Agent** | A sealed-runtime AI worker with specialized Crown Jewel powers |
| **Agency** | A coordinated team of cognitive agents with shared task management |
| **Sealed Runtime** | Source-blocked, memory-isolated execution environment for agents |
| **Artifact Pack** | An exported capability bundle containing code, runtime, docs, and tests |
| **Mini-Runtime** | Standalone execution environment bundled with exported artifacts |

## Ascension

| Term | Definition |
|------|-----------|

| **Dual-Layer Architecture** | Original code + cognitive overlay running together |
