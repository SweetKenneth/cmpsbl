## 1. What We Sell

CMPSBL has **two revenue channels**:

### Channel 1 — Platform Subscriptions
Access to the CMPSBL cognitive operating system with tiered capacity.

| Tier | Price | Audience |
|------|-------|----------|
| **Builder** | Included | Developers exploring the platform |
| **Studio** | $29/mo | Solo developers, small projects |
| **Creator** | $49/mo | Active developers, growing projects |
| **Architect** | $79/mo | Teams, production workloads |
| **Enterprise** | Custom pricing | Organizations requiring federated local substrates |

Tiers scale by: active slots, memory capacity, discovery rate, priority routing, and expanded capabilities (memory packs, etc.).

> **Governor** is NOT a pricing tier. It is a reserved super-admin role for a single system operator (the founder or designated successor) with God Mode access across the entire substrate.

### Channel 2 — Standalone Products (Engines & Agents)
Individual primitives sold as sealed, zero-dependency artifacts through the Ascension system.

| Tier | Price | Quality Level |
|------|-------|---------------|
| **Free** | $0 | Community-contributed, basic |
| **Starter** | $79 | Functional, limited customization |
| **Pro** | $129 | Full-featured, production-ready |
| **Elite** | $159 | Advanced capabilities, priority support |

## 3. The Ascension Export Pipeline

This is our most unique product feature. The flow:

```
Upload artifact
    ↓
Discovery — system analyzes capability combinations
    ↓
CJPI Scoring — Novelty, Utility, Complexity, Composability
    ↓
Tier Classification — Mint → Prime → Relic → Mythic → Apex
    ↓
Export — single-file, zero-dependency "drop-in" distribution
    ↓
25 languages — 18 software + 7 HDL
```

### What the customer gets:
- A **single file** (e.g., `cmpsbl.ts`, `cmpsbl.py`, `cmpsbl.rs`) containing:
  - §1 Mini-Runtime™ — Scoring and orchestration
  - §2 Module Effects — Logic for all included primitives
  - §3 Runtime Bridge — Chain execution
  - §4 Capability API — Public interface

### Key selling points:
- **Zero dependencies** — drop it into any project
- **25 languages** — works in their stack, whatever it is
- **IP-protected** — black-boxed proprietary logic
- **One-way export** — artifacts are final, production-ready products (not re-ingested)

## 4. CJPI Scoring System

Every discovered capability receives a CJPI score:

| Dimension | Weight | What It Measures |
|-----------|--------|-----------------|
| **Novelty** | 30% | How unique is this combination? |
| **Utility** | 30% | How practically useful is this? |
| **Complexity** | 20% | How sophisticated is the orchestration? |
| **Composability** | 20% | How well does it combine with other capabilities? |

### Tier Thresholds
| Tier | Score Range | Rarity |
|------|------------|--------|
| **Apex** | 92+ | Ultra-rare, breakthrough capability |
| **Mythic** | 80–91 | Exceptional, high-value |
| **Relic** | 65–79 | Strong, reliable |
| **Prime** | 45–64 | Solid, production-worthy |
| **Mint** | 0–44 | Entry-level, foundational |
