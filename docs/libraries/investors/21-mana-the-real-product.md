| Property | Detail |

| **Permission required** | None — attachment is non-cooperative |

Mana doesn't need the developer's permission to attach. It wraps around the runtime boundary of any function, module, or service — observing inputs, outputs, and behavioral patterns. The original code doesn't know Mana is there.

This is not malware. This is **software symbiosis** — the same way monitoring agents, APM tools, and security scanners wrap around applications today, but with:
- Deterministic governance (Lex)
- Cryptographic proof of non-modification
- Full behavioral audit trail
