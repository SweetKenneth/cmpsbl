# Primitives Guide

---

## Organs — Internal Infrastructure

| Primitive | Purpose | Key Actions |
|-----------|---------|-------------|
| **CORE** | Kernel boot, system integrity | Health check, matrix calculation |
| **SYSTEM** | Lifecycle, configuration | Environment management |
| **BRAIN** | Reasoning, pattern recognition | `reason`, `learn` |
| **MEMORY** | State persistence, retrieval | `store`, `retrieve`, `search` |
| **NERVE** | Signal bus, event orchestration | Signal routing, gate management |
| **RELAY** | Message delivery, webhooks | Webhook dispatch, signal forwarding |
| **RIPPLE** | Task orchestration, event propagation | Queue management, dead letter recovery |
| **ACCESS** | Authentication, API keys | Key management, quota enforcement |
| **IDENTITY** | Identity resolution, sessions | Session management, fingerprinting |
| **AUDIT** | Tamper-evident logging | Chain verification, forensic search |

## Layers — Ambient Overlays

| Primitive | Purpose | Behavior |
|-----------|---------|----------|
| **DEFENSE** | Terminal security boundary | Always-on threat assessment |
| **IMMUNITY** | Cross-cutting resilience | Adaptive pattern learning |
| **GOVERNANCE** | Supervisory policy enforcement | 4-mode operation control |
| **INTENT** | Signal translation | Cross-primitive goal decomposition |
| **EVOLUTION** | Version management | SEBA pipeline orchestration |
| **SHADOW** | Isolated testing | Shadow runs, divergence scoring |
| **PHANTOM** | Counter-intelligence | Decoy operations, canary tokens |

## Engines — Processing Powerhouses

| Primitive | Purpose | Key Actions |
|-----------|---------|-------------|
| **DREAM** | Heuristic synthesis | Self-improvement cycles |
| **CORTEX** | Pipeline orchestration | `pipeline`, `compose` |
| **NEXUS** | AI provider routing | `route`, `health`, `consensus` |
| **ORACLE** | Predictive modeling | `predict`, `simulate` |
| **FORGE** | Artifact manufacturing | `generate`, `template` |
| **ECHO** | Digital twin simulation | Scenario replay |
| **ECONOMY** | Cost tracking | `usage`, `quota`, `cost` |
| **ENGINEER** | Maintenance intelligence | Health scanning, proposals |
| **ATLAS** | Governance hub | Capability mapping, marketplace |
| **CLM** | Constant learning | Knowledge distillation |

## Agents — Autonomous Actors

| Primitive | Purpose | Key Actions |
|-----------|---------|-------------|
| **DECODE** | Natural language understanding | `process`, `stream` |
| **ENCODE** | Code and content generation | `generate`, `format` |
| **VISION** | Telemetry, anomaly detection | `analyze`, `render` |
| **HARVEST** | Data acquisition, ETL | `ingest`, `normalize` |
| **LINGUA** | Translation, localization | `translate`, `detect` |
| **COMPASS** | Geospatial, trend analysis | `trends`, `navigate` |
| **CONSCIENCE** | Ethical assessment | Bias detection |
| **TREATY** | SLA management | Contract enforcement |
| **SOVEREIGN** | Data sovereignty | Jurisdiction compliance |
| **MEDIC** | Diagnostics, self-repair | `diagnose`, `repair` |
| **INCLUSIVE** | Accessibility scanning | WCAG compliance |
| **INTEGRATION** | External connectivity | Adapters, webhooks |
| **REFLEX** | Edge computing | Low-latency response |
| **SANDBOX** | Isolated execution | Speculative runs |
| **OBSERVER** | System observation | Telemetry collection |

## When to Use What

| I want to... | Use |
|-------------|-----|
| Understand user input | DECODE Agent |
| Generate code or content | ENCODE Agent |
| Route to best AI model | NEXUS Engine |
| Chain multiple AI steps | CORTEX Engine |
| Store/retrieve data | MEMORY Organ |
| Translate content | LINGUA Agent |
| Make predictions | ORACLE Engine |
| Check accessibility | INCLUSIVE Agent |
| Generate artifacts | FORGE Engine |
| Ingest external data | HARVEST Agent |
| Run simulations | ECHO Engine |
| Check ethics/bias | CONSCIENCE Agent |
