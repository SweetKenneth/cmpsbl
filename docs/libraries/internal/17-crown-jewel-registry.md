## Overview

54 capabilities are classified as **Crown Jewels** — the substrate's most valuable algorithms and patterns. They are:

- Excluded from all external access tiers
- Not visible in API catalogs or documentation
- Governor-only access
- Source-blocked from agent runtimes
- Verified monthly by black-box enforcement

## Classification Criteria

A capability is classified as a Crown Jewel when it meets three or more of:

1. **Irreplicability** — cannot be reconstructed from public information
2. **High CJPI** — scored ≥ 95 in discovery pipeline
3. **Structural dependency** — other primitives depend on it
4. **Competitive advantage** — provides defensible moat
5. **Sensitivity** — exposure would weaken system integrity

## S-Tier Vault

The highest-tier Crown Jewels (CJPI ≥ 100) are automatically promoted to the S-Tier Vault — a governor-curated collection of the substrate's most valuable assets. S-Tier discoveries represent capabilities that:

- Have been validated through CDM (Constant Discovery Mode)
- Passed all SEBA gates including TSAC
- Were confirmed by governor review
- Represent genuine architectural innovations
