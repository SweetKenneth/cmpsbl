## Purpose

Where docs 06 and 07 protect specific mechanisms, this filing protects the **architectural pattern** that defines the category: any system in which (a) cognitive output is generated, (b) the output is owned by the originating subject, (c) the output is byte-reproducible from a logged receipt, and (d) no generative AI participates in the determinative computation.

This is the umbrella. Anyone building in the Reflective/Precognitive AI category will need to license something from this filing.

---

## Independent Claim 1

A computer-implemented system comprising:

1. an input subsystem configured to capture interaction signal generated by an originating user;
2. a determinative computation subsystem configured to derive a cognitive output from said interaction signal, wherein said determinative computation subsystem does not invoke any generative machine-learning model in deriving the cognitive output;
3. a rendering subsystem configured to render the cognitive output to the originating user via deterministic template substitution;
4. a receipt subsystem configured to emit a cryptographic receipt comprising at least: a hash of the captured interaction signal, an identifier of the version of the determinative computation, a hash of the cognitive output, and a digital signature; and
5. an access-control subsystem configured to restrict the cognitive output and the receipt to a scope owned by and exportable by the originating user.

---

## Dependent Claims

- **2.** The system of claim 1, wherein the determinative computation subsystem is byte-reproducible such that identical inputs and identical version yield identical output.
- **3.** The system of claim 1, wherein the rendering subsystem renders said cognitive output via substitution into a versioned template phrase bank.
- **4.** The system of claim 1, wherein the access-control subsystem permits the originating user to export the cognitive output and the receipt independent of the system operator.
- **5.** The system of claim 1, further comprising a generative subsystem configured to interact with the originating user, wherein outputs of said generative subsystem are explicitly labeled as generative and are excluded from the determinative computation subsystem.
- **6.** The system of claim 5, wherein interaction signal generated through the generative subsystem is captured by the input subsystem and provided as input to the determinative computation subsystem.
- **7.** The system of claim 1, wherein the receipt subsystem persists receipts in an append-only structure suitable for third-party audit.
- **8.** The system of claim 1, wherein the cognitive output is selected from the group consisting of: a reflective summarization, a forecast, a counterfactual disclosure, a calibration history, and a thought-provenance certificate.

---

## Why Claims 5 and 6 Matter

These two claims explicitly cover the **wrap-an-LLM-with-deterministic-substrate pattern.** That is the architecture every competitor will eventually try (because LLMs are easy and the deterministic layer is hard). This filing makes that pattern licensable from us.

In other words: **OpenAI, Anthropic, and Google can build chatbots all day. The moment they wrap one with deterministic reflective output, they license from us.**

## Counsel Brief (one paragraph)

> This filing protects the architectural pattern shared by all products in the Reflective and Precognitive AI category: an input subsystem capturing user interaction signal, a determinative computation subsystem operating without generative AI, a deterministic rendering subsystem, a cryptographic receipt subsystem, and a user-owned access-control subsystem. Critically, dependent claims 5 and 6 cover the architecture in which a generative subsystem (e.g., an LLM chatbot) is composed alongside the determinative computation subsystem to produce labeled, separated outputs — covering the most likely competitor architecture. The filing strategy is to allow narrower independent claims if necessary to preserve claims 5–6, which constitute the licensing engine of the category.
