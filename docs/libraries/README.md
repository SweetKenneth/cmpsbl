## Conventions

- Primitive names are always written in ALL CAPS (e.g., NEXUS, DECODE, DEFENSE)
- The 40 core components are called **primitives**, organized into four **categories**: Organs, Layers, Engines, and Agents
- Automated multi-primitive workflows are called **memory chains**
- Tone is neutral, technical, and OS-manual grade in Internal; accessible and clear in Public and Users
- No marketing language in Internal documents
- All documents use current terminology per the CMPSBL taxonomy
