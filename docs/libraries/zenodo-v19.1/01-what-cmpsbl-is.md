# What CMPSBL® Is — v19.1

## One Sentence

CMPSBL® is **governed cognitive infrastructure** that wraps any source code with patented runtime layers (Mana) through a deterministic, phase-locked restoration pipeline (Ascension v2) — producing sealed, fingerprinted artifacts in 9 languages with cryptographic receipts.

## What It Is Not

- It is **not an AI agent platform**. The world is full of agent frameworks; CMPSBL is the substrate underneath them.
- It is **not a no-code tool**. It operates on real source code.
- It is **not a chatbot**. It has one named interface (DECODE) and one product (Ascension v2).
- It is **not making thinking machines**. The infrastructure is governed and deterministic; "intelligence" claims are bounded by what the code actually does.

## What It Actually Does

1. **Takes your source code** (single file or repo)
2. **Runs the Ascension pipeline:** pre-gate → discovery → locking → ascension → export
3. **Optionally attaches Mana layers** in Step 2 (Enhance) — Crown Jewel layers, SDK-built layers
4. **Emits a sealed, polyglot artifact** in up to 9 languages, with a Merkle-linked receipt
5. **Verifies anywhere** via fingerprint — same input + same layers = byte-identical output
