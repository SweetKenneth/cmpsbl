# DREAM Synthesis — Algorithmic, Sub-Threshold, No AI

## What DREAM Is

DREAM is the substrate's **algorithmic synthesis engine**. It surfaces patterns from Memory Stream discoveries that fall **below the conscious-output threshold** but above noise.

## What DREAM Is Not

- ❌ Not an AI model
- ❌ Not a prompt-driven generator
- ❌ Not stochastic
- ❌ Not "the system dreams" in any anthropomorphic sense

The naming is deliberate — "DREAM" describes a *function* (sub-threshold synthesis), not a metaphor about consciousness.

## How It Works (Public Surface)

1. Memory Stream produces continuous discovery events
2. Most events are above the surfacing threshold and become Showroom drops
3. Some events are **just below** threshold — interesting but not actionable
4. DREAM aggregates these sub-threshold events using deterministic algorithmic scoring
5. When enough sub-threshold signal converges on a pattern, DREAM surfaces it
6. Surfaced patterns feed back into the Compiler for graduation

## Why Patentable

Because DREAM is **algorithmic and deterministic**:
- Same input stream + same scoring weights = same surfaced patterns
- No AI model in the loop
- Reproducible across runs
- Verifiable via fingerprint

The combination of (a) sub-threshold pattern surfacing, (b) deterministic scoring, and (c) algorithmic synthesis without an AI model is the patent-relevant claim surface.
