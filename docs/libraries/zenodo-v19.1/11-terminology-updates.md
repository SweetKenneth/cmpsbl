# Terminology Updates — v13.5 → v19.1

> Quiet renames and retired terms. The substrate didn't change — the words did.

## Renamed (Public-Facing)

| v13.5 / v19 term | v19.1 term | Reason |
|------------------|------------|--------|
| cognitive substrate | governed cognitive infrastructure | More honest — emphasizes governance, not "thinking" |
| autonomous agents | policy-governed AI workers | Distinguishes CMPSBL Cognitives from generic agents |
| self-healing | self-healing pipeline (in training) | Honest about maturity stage |
| MODERNIZER | EVOLUTION | Cleaner naming, single canonical engine name |
| EVOLVE | EVOLUTION | Same — collapsing alias |
| Modules | Primitives | Aligns with the 40-Primitive matrix |
| Nodes | Primitives, Engines, Agents, or Layers (depending on context) | "Node" was overloaded |
| Mesh | Layers | "Mesh" implied a topology that doesn't exist |
| 40-node | 40-Primitive | Same as above |
| framework / system / platform | substrate | One canonical term |
| our team | we / CMPSBL | Solo founder model |
| triggered | runs autonomously | Memory Stream isn't triggered — it loops |
