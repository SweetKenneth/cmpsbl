== Description ==

**PromptFluid Clarity** is an AI-powered accessibility scanner that helps you make your WordPress site compliant with WCAG 2.2 standards. Get real-time accessibility insights, detailed issue reports, and AI-powered fix recommendations.

= Key Features =

* **Real-time Accessibility Scanning** - Scan pages as you edit them
* **WCAG 2.2 Compliance** - Check against Level A, AA, and AAA standards
* **AI-Powered Recommendations** - Get intelligent fix suggestions
* **Detailed Issue Reports** - Understand exactly what needs fixing
* **Priority Scoring** - Focus on high-impact issues first
* **Export Reports** - Generate PDF reports for stakeholders
* **Scheduled Scans** - Automatic daily scanning of your entire site
* **Historical Tracking** - Monitor accessibility improvements over time

= Why Accessibility Matters =

* **Legal Compliance** - Meet ADA, Section 508, and international accessibility laws
* **Better SEO** - Accessible sites rank better in search engines
* **Wider Audience** - Reach users with disabilities (15% of global population)
* **Better UX** - Accessible sites are easier for everyone to use

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/promptfluid-clarity/` or install through WordPress plugins screen
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Navigate to **PromptFluid Clarity** in your admin menu
4. Start your 7-day free trial (no credit card required)
5. Begin scanning your pages for accessibility issues

== Frequently Asked Questions ==

= Is this plugin free? =

The plugin is free to install with a 7-day trial. After the trial, you'll need a paid subscription starting at $19/mo.

= What accessibility standards does it check? =

Clarity scans against WCAG 2.2 Level A, AA, and AAA standards, as well as Section 508 compliance.

= Does it automatically fix issues? =

Clarity provides detailed recommendations and code snippets, but you'll need to implement the fixes manually to ensure they match your design.

= How often does it scan my site? =

You can run manual scans anytime, and the plugin automatically runs a full site scan daily (configurable).

= Will this slow down my site? =

No. Scans happen in the background and don't affect your site's frontend performance.

= Does it work with page builders? =

Yes! Clarity works with Gutenberg, Elementor, Divi, WPBakery, and all major page builders.

= Can I export reports? =

Yes, you can export detailed PDF reports for stakeholders or compliance documentation.

= Is my data private? =

Yes. Scans are processed securely, and we never share your data with third parties. See our privacy policy: https://www.promptfluid.com/privacy
