

# Enhancement Mesh — Always-On Substrate Amplification Layer

## Concept

The Enhancement Mesh is a new system layer that selects capabilities which should run **continuously** (not event-triggered) to provide passive, substrate-wide technological uplift. Unlike activation rules (which fire on signals), Enhancement Mesh capabilities are **always active**, running on heartbeat intervals, providing ambient intelligence that elevates every node's baseline performance.
